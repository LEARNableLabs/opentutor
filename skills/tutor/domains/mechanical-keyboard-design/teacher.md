# Mechanical keyboard design — switches, PCBs, and firmware — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 12 lessons (39%)
- **Socratic questions** — 6 lessons (19%)
- **real-world application challenges** — 4 lessons (13%)
- **teach-back exercises (student explains)** — 4 lessons (13%)
- **review and consolidation sessions** — 4 lessons (13%)
- **curated resource exploration** — 1 lessons (3%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: video lectures, interactive tools, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Gentle ramp — heavily front-loaded with accessible material before increasing complexity.

Distribution: 52% accessible (1-2), 32% standard (3), 16% challenging (4-5).

Difficulty peaks:
- Day 12: "How do you route a matrix without crossing traces?" (difficulty 4)
- Day 15: "How would you design a 4x4 macropad PCB from scratch?" (difficulty 4)
- Day 25: "How do you create custom macros and advanced key behaviors?" (difficulty 4)
- Day 26: "How do you optimize firmware for latency and power consumption?" (difficulty 4)
- Day 31: "How would you build a complete custom keyboard from concept to working prototype?" (difficulty 5)
