# Luthiery — building stringed instruments — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 10 lessons (38%)
- **real-world application challenges** — 4 lessons (15%)
- **Socratic questions** — 4 lessons (15%)
- **review and consolidation sessions** — 4 lessons (15%)
- **curated resource exploration** — 2 lessons (8%)
- **teach-back exercises (student explains)** — 2 lessons (8%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 31% accessible (1-2), 38% standard (3), 31% challenging (4-5).

Difficulty peaks:
- Day 7: "How does the bridge transmit vibration without choking the top?" (difficulty 4)
- Day 8: "What's actually happening when a guitar 'booms' in the low end?" (difficulty 4)
- Day 14: "Why is the Spanish heel joint so revered (and so hard)?" (difficulty 5)
- Day 16: "What's the difference between X-bracing and fan bracing?" (difficulty 4)
- Day 17: "How thin is too thin for a soundboard?" (difficulty 4)

## Domain Hooks
This field covers luthiery — building stringed instruments, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.
