# Evolutionary Biology and Phylogenetics — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **Socratic questions** — 10 lessons (31%)
- **concept-focused mini-lessons** — 9 lessons (28%)
- **real-world application challenges** — 5 lessons (16%)
- **teach-back exercises (student explains)** — 4 lessons (13%)
- **review and consolidation sessions** — 4 lessons (13%)

Primary format: Socratic questions.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 50% accessible (1-2), 31% standard (3), 19% challenging (4-5).

Difficulty peaks:
- Day 22: "How do we find the tree that best explains our DNA data?" (difficulty 4)
- Day 23: "Why do we need different models for how DNA sequences evolve?" (difficulty 4)
