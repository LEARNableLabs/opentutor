# HEMA Concept Map

## Core Dependency Graph

```
Source Literacy (L1-3)
├─ Visual Language (manuscript illustrations, period conventions)
├─ Source Criticism (dating, provenance, authorship)
└─ Historical Masters (Liechtenauer, Fiore, Meyer)
    │
    ├─ German Longsword Tradition (L4-7)
    │   ├─ Indes (timing/simultaneity) → Vor/Nach (initiative) → Tempo
    │   ├─ Merkverse (mnemonic poetry) → Gloss Interpretation
    │   └─ Liechtenauer's Zettel
    │
    ├─ Italian Tradition (L8-10)
    │   ├─ Weapon Evolution (rapier vs longsword)
    │   ├─ Misura (measure) & Tempo
    │   ├─ Fiore System (diagrams, segno, guards)
    │   └─ Civilian Dueling Culture
    │
    ├─ Blade Mechanics (L11-13)
    │   ├─ Binding & Winding
    │   ├─ Strong/Weak of Blade (Starke/Schwäche)
    │   ├─ Leverage Principles
    │   └─ Guard Structure
    │
    └─ Cross-Weapon Principles (L14-15)
        ├─ Weapon Scaling (dagger, longsword, polearms)
        ├─ Universal Principles
        └─ Pedagogical Progression (wrestling → dagger → sword)

Historical Context (L16-17)
├─ Social Context (guilds, Fechtschulen, class)
├─ Armored vs Unarmored Combat
└─ Weapon Evolution & Technology

Modern Interpretation (L18-19)
├─ Interpretation Methodology
├─ Experimental Archaeology
├─ Living Tradition vs Reconstruction
└─ Evidence Standards

Modern Practice (L20-22)
├─ Sport vs Research vs Martial Art
├─ Safety Protocols & Equipment
├─ Tournament Formats (cutting, sparring, forms)
└─ Community Organizations

Advanced Synthesis (L23-25)
├─ Pedagogical Design (drill creation)
├─ Source-to-Practice Translation
├─ Productive Debate vs Bike-shedding
└─ Comprehensive Interpretation
```

## Concept Clusters

### Foundation Layer (Lessons 1-3)
**Entry requirement**: Basic historical literacy, sword terminology  
**Enables**: All subsequent modules  
**Key skills**: Reading fight books, evaluating sources, identifying major traditions

### Technical Systems (Lessons 4-15)
**Depends on**: Foundation layer  
**Two parallel tracks**:
- **German Track** (L4-7): Timing theory, verse interpretation, Liechtenauer system
- **Italian Track** (L8-10): Measure/tempo, Fiore diagrams, rapier theory

**Convergence** (L11-13): Blade mechanics common to both traditions  
**Generalization** (L14-15): Cross-weapon principles

### Contextual Understanding (Lessons 16-17)
**Depends on**: Foundation + at least one technical track  
**Enriches**: Interpretation of all technical material  
**Key insight**: Techniques can't be separated from historical context

### Meta-Practice (Lessons 18-25)
**Depends on**: All previous modules  
**Applies**: Critical thinking to interpretation and practice  
**Culminates in**: Independent interpretation capability

## Critical Path

The minimum sequence to achieve basic competency:

1. **Source Literacy** (L1-3) — must come first
2. **One Technical Tradition** (either L4-7 OR L8-10) — choose based on interest
3. **Blade Mechanics** (L11-12) — universal principles
4. **Interpretation Methodology** (L18) — apply critical thinking
5. **Final Synthesis** (L25) — demonstrate capability

## Parallel Learning Opportunities

Students can explore these in any order after Foundation:
- German vs Italian traditions (L4-10)
- Historical Context (L16-17) can be studied anytime after L3
- Modern Practice (L20-22) can be studied alongside technical work

## Review Checkpoints

- **L7**: First review — timing concepts across German tradition
- **L13**: Second review — blade mechanics across both traditions
- **L19**: Third review — interpretation methodology with ambiguous text
- **L25**: Final review — comprehensive demonstration

## Prerequisites for Advanced Topics

To attempt L23-24 (advanced synthesis), students should have:
- Completed at least one full technical tradition (German OR Italian)
- Understood blade mechanics (L11-12)
- Grasped interpretation methodology (L18)
- Engaged with community debates (evidenced through discussions)

## Common Misconception Nodes

These concepts frequently trip up intermediate students:

1. **Indes** (L4) — often conflated with "immediate" rather than "simultaneously responsive"
2. **Vor/Nach** (L6) — misunderstood as "offense/defense" rather than "initiative states"
3. **Source Authority** (L2) — assuming all historical sources are equally reliable
4. **Sport vs Historical** (L18, L20) — false dichotomy; they inform each other
5. **Universal Principles** (L14) — over-generalizing vs recognizing weapon-specific adaptations

## Concept Maturity Indicators

**Basic** (early lessons):
- Can identify a historical source
- Can name major masters
- Understands basic timing vocabulary

**Intermediate** (middle lessons):
- Can interpret a treatise passage with guidance
- Understands differences between German/Italian approaches
- Can explain blade mechanics principles
- Recognizes interpretation ambiguity

**Advanced** (final lessons):
- Can independently interpret a treatise section
- Can create training drills from source material
- Can argue for an interpretation with evidence
- Understands limitations of historical knowledge
- Can critically evaluate modern HEMA practice
