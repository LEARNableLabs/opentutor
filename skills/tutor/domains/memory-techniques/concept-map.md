# Memory Techniques — Concept Map

## Core Concepts (in learning order)

1. **Forgetting curve** — exponential decay of memory over time without review (Ebbinghaus)
2. **Memory consolidation** — process of stabilizing memory traces from short-term to long-term storage
3. **Interference theory** — competing memories disrupt recall
4. **Spatial memory** — recall anchored to physical or imagined locations (hippocampus-dependent)
5. **Episodic encoding** — memories formed with contextual details (time, place, emotion)
6. **Encoding strength** — how deeply/vividly information is processed determines retrieval ease
7. **Active recall** — retrieving information from memory strengthens it more than passive review
8. **Testing effect** — the act of retrieval itself improves long-term retention
9. **Method of loci** — ancient mnemonic technique using spatial memory to encode information. Depends on: spatial memory, episodic encoding, encoding strength
10. **Memory palace** — specific implementation of method of loci using familiar locations. Depends on: method of loci, spatial memory
11. **Distinct loci** — unique, memorable locations within a memory palace. Depends on: spatial memory
12. **Visualization** — creating vivid mental images to encode information. Depends on: encoding strength
13. **Dual coding** — encoding information both verbally and visually. Depends on: visualization, encoding strength
14. **Symbolic encoding** — representing abstract concepts with concrete images. Depends on: visualization, dual coding
15. **Emotional encoding** — using emotion to strengthen memory traces. Depends on: encoding strength, episodic encoding
16. **Spaced repetition** — reviewing information at increasing intervals to combat forgetting curve. Depends on: forgetting curve, active recall
17. **Optimal intervals** — mathematically determined review timing based on memory strength. Depends on: spaced repetition, forgetting curve
18. **SM-2 algorithm** — specific spaced repetition algorithm used in Anki and early SuperMemo. Depends on: spaced repetition, optimal intervals
19. **Ease factor** — metric tracking how easily you recall an item (used in interval calculation). Depends on: SM-2 algorithm
20. **Minimum information principle** — breaking knowledge into smallest testable units. Depends on: active recall
21. **Cloze deletion** — flashcard format with fill-in-the-blank structure. Depends on: minimum information principle, active recall
22. **Deck structure** — organization of flashcard collections by topic/difficulty. Depends on: spaced repetition
23. **Technique integration** — combining method of loci with spaced repetition for dual reinforcement. Depends on: method of loci, spaced repetition, dual coding
24. **Meta-learning** — using memory techniques to improve the learning process itself. Depends on: active recall, spaced repetition, meta-cognition

## Dependencies

### Foundational Chain
- **Active recall** requires understanding the **testing effect** because retrieval practice is the mechanism
- **Spaced repetition** requires understanding the **forgetting curve** because optimal timing derives from decay rates
- **Encoding strength** determines both **method of loci** effectiveness and **spaced repetition** starting intervals

### Method of Loci Chain
- **Memory palaces** require **spatial memory** because the hippocampus encodes location automatically
- **Distinct loci** require **spatial familiarity** because you need stable mental navigation
- **Symbolic encoding** requires **visualization** because abstract→concrete translation needs imagery
- **Emotional encoding** enhances **episodic encoding** because emotion strengthens memory consolidation

### Spaced Repetition Chain
- **SM-2 algorithm** builds on **optimal intervals** by adjusting timing based on performance
- **Ease factor** modifies **interval calculation** to personalize the forgetting curve
- **Minimum information principle** improves **active recall** by reducing cognitive load per card
- **Cloze deletion** implements **minimum information principle** in a specific card format

### Integration
- **Technique integration** combines **method of loci** (spatial encoding) and **spaced repetition** (temporal scheduling) because they target different memory systems
- **Dual coding** benefits from **visualization** (method of loci) and **active recall** (spaced repetition) simultaneously
- **Meta-learning** requires mastery of both **spaced repetition** and **encoding techniques** to optimize personal learning

## Bottlenecks

Students often struggle at these conceptual transitions:

1. **Active recall → Spaced repetition** — understanding that testing is not just assessment but the learning mechanism itself
2. **Visualization → Symbolic encoding** — translating abstract concepts (justice, recursion, thermodynamics) into memorable images
3. **Spatial memory → Method of loci** — realizing that mental navigation can be as effective as physical navigation
4. **Forgetting curve → Optimal intervals** — grasping that intervals should expand exponentially, not linearly
5. **Individual techniques → Technique integration** — recognizing when to combine vs. when to use each alone

## Prerequisite Topics

- **Basic metacognition** — needed for active recall, meta-learning (awareness of own thinking)
- **Comfort with experimentation** — needed for personalization, meta-learning (willingness to test and adjust)
- **No formal background required** — memory techniques are accessible regardless of academic preparation

## Common Misconceptions

- "Memory palaces are only for memorizing lists" — Actually effective for abstract concepts when combined with symbolic encoding
- "Spaced repetition is just flashcards" — The algorithm and timing are what matter, not the format
- "You need a photographic memory" — Memory techniques work by leveraging normal cognitive processes, not exceptional abilities
- "More vivid = better always" — Extreme imagery can be distracting; effectiveness depends on personal style
- "Cramming before reviews" — Defeats the spacing effect; consistency beats intensity
