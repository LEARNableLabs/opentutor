# Memory Techniques — Research Summary

## Topic Overview

Memory techniques encompass systematic methods for enhancing recall and retention, with two major pillars: **method of loci** (spatial memory encoding) and **spaced repetition theory** (optimal review scheduling based on forgetting curves).

## Major Subtopics

### 1. Foundations of Memory Science
- Working memory vs. long-term memory systems
- Encoding, storage, and retrieval processes
- The forgetting curve (Ebbinghaus)
- Memory consolidation and interference theory

### 2. Method of Loci (Memory Palace)
- Ancient Greek origins (Simonides of Ceos)
- Spatial memory and the hippocampus
- Creating and navigating memory palaces
- Encoding techniques (vividness, action, emotion)
- Applications: speeches, lists, facts, abstract concepts
- Memory championship techniques

### 3. Spaced Repetition Theory
- Forgetting curve and optimal timing
- SuperMemo algorithms (SM-2, SM-17)
- Active recall vs. passive review
- Leitner system
- Practical implementations (Anki, SuperMemo, RemNote)
- Research on learning efficiency and retention rates

### 4. Integration and Advanced Applications
- Combining spatial and temporal techniques
- Domain-specific adaptations (languages, medicine, mathematics)
- Meta-learning: tracking your own forgetting curves
- Dual coding theory
- Chunking and elaborative encoding

## Student Prerequisites

For intermediate level:
- Basic understanding of how learning works (metacognition)
- Comfort with self-experimentation and tracking
- Willingness to practice regularly (spaced repetition requires consistency)
- No specific academic background required

## Pedagogical Approach

This topic benefits from:
1. **Immediate practice** — theory is best learned by doing
2. **Personal experimentation** — students build their own palaces and decks
3. **Concrete examples** — abstract concepts encoded with vivid imagery
4. **Gradual complexity** — start with simple lists, progress to complex material
5. **Meta-cognitive reflection** — tracking what works for their brain
