# Memory Techniques — Resources

## Primary Sources (for lesson content)

### Foundational Texts
- **Moonwalking with Einstein** (Joshua Foer, 2011) — Journalist trains for memory championships, explores history and science of mnemonics. Accessible entry point for intermediate learners. Covers method of loci, memory palaces, and competitive memory.
- **Make It Stick: The Science of Successful Learning** (Brown, Roediger, McDaniel, 2014) — Research-backed learning techniques including spaced repetition and retrieval practice. Excellent for understanding *why* techniques work.
- **The Art of Memory** (Frances Yates, 1966) — Historical survey from ancient Greece to Renaissance. Dense but fascinating for context on method of loci's cultural significance.

### Online Courses
- **Learning How to Learn** (Coursera, Barbara Oakley & Terrence Sejnowski) — https://www.coursera.org/learn/learning-how-to-learn — Popular MOOC covering memory, chunking, and meta-learning. Modules on memory palaces and spaced repetition.
- **SuperMemo Guru** (Piotr Wozniak) — https://www.supermemo.com/en/blog — Creator's blog with deep algorithmic details and personal philosophy. Advanced but authoritative.

### Research Papers
- Roediger, H.L. & Karpicke, J.D. (2006). "The Power of Testing Memory" — Foundational paper on testing effect and retrieval practice.
- Ebbinghaus, H. (1885). "Memory: A Contribution to Experimental Psychology" — Original forgetting curve research. Historical but essential.
- Maguire, E.A. et al. (2003). "Routes to remembering: The brains behind superior memory" — Brain imaging of memory athletes showing technique training, not innate ability.

## Supplementary (for engagement)

### Interactive Tools
- **Nicky Case's "How To Remember Anything Forever-ish"** — https://ncase.me/remember/ — Beautiful interactive explainer of spaced repetition with comic-style visuals. Perfect for visual learners. ~20 minutes to complete.
- **Gwern Branwen's Spaced Repetition Guide** — https://www.gwern.net/Spaced-repetition — Comprehensive guide covering theory, algorithms, what to memorize, and personal experiments. Dense but thorough. Intermediate to advanced.
- **Memory League** — https://www.memoryleague.com/ — Online platform for competitive memory training. Games for cards, numbers, names, images. Good for gamified practice.

### Videos
- **Memory Sports TV** — https://www.youtube.com/c/MemorySportTV — Channel covering memory championships, technique tutorials, and athlete interviews. High production quality.
- **Ali Abdaal's Anki Tutorials** — https://www.youtube.com/watch?v=5urUZUWoTLo — Medical student's guide to using Anki for studying. Practical deck design tips.
- **3Blue1Brown — "What is a convolution?"** (example of math visualization) — https://www.youtube.com/c/3blue1brown — Not memory-specific, but excellent model for encoding abstract math concepts visually.

### Software & Tools
- **Anki** — https://apps.ankiweb.net/ — Open-source spaced repetition with mobile sync. Default SM-2 algorithm, highly customizable. Most popular SRS tool.
- **SuperMemo** — https://www.supermemo.com/ — Original SRS software with advanced algorithms (SM-17). Windows-only, steeper learning curve.
- **RemNote** — https://www.remnote.com/ — Combines outlining/note-taking with built-in spaced repetition. Good for students who want integrated workflow.
- **Mnemosyne** — https://mnemosyne-proj.org/ — Open-source SRS focused on research-backed algorithms. Simpler interface than Anki.

### Communities
- **Art of Memory Forum** — https://artofmemory.com/ — Largest online community for memory techniques. Forums, wikis, and technique tutorials. Active and welcoming to beginners.
- **r/Anki** — https://www.reddit.com/r/Anki/ — Reddit community for Anki users. Deck sharing, troubleshooting, and optimization tips.
- **r/MemoryPalace** — https://www.reddit.com/r/MemoryPalace/ — Community focused on method of loci and memory palaces.

## Unexpected Connections

### Memory Palaces in Fiction
- **"The Memory Palace of Matteo Ricci"** (Jonathan Spence) — Historical account of Jesuit missionary using memory palaces in Ming Dynasty China. Fascinating cultural exchange story.
- **"Hannibal" TV series** — Hannibal Lecter uses elaborate memory palaces. Dramatized but visually striking representation.

### Cross-Disciplinary Applications
- **Method of loci for programming** — Encoding data structures and algorithms spatially. Example: binary tree as a physical tree in a palace room.
- **Spaced repetition for language learning** — Massive Anki shared decks for vocabulary (e.g., "10,000 Most Common German Words"). Refold language learning method.
- **Medical education** — Anatomy, pharmacology, and diagnostic criteria benefit heavily from both mnemonics and SRS. AnKing deck (30,000+ cards for USMLE Step 1).
- **Music theory** — Encoding scales, chord progressions, and theory concepts. Less common but effective application.

### Historical Oddities
- **Giordano Bruno** — Renaissance philosopher burned at stake (1600). Used memory palaces to encode entire cosmological systems. Yates's "The Art of Memory" covers in detail.
- **Simonides of Ceos** — Greek poet credited with inventing method of loci after identifying banquet hall victims by remembering their seating positions.
- **Cicero's "De Oratore"** — Roman rhetoric text describing architectural mnemonics for speechmaking.

### Neuroscience Deep Dives
- **Hippocampal place cells** — Nobel Prize-winning discovery (O'Keefe & Moser, 2014). Explains why spatial memory is so robust.
- **Sleep and memory consolidation** — Matthew Walker's "Why We Sleep" covers memory replay during slow-wave sleep.
- **Reconsolidation** — Memories become labile upon retrieval. Implications for updating vs. strengthening memories. Research by Karim Nader.

## Tools for Practice

### Physical/Analog
- **Leitner box** — DIY cardboard box system with expanding compartments. Pre-digital spaced repetition.
- **Index cards** — Traditional flashcards. Tactile and distraction-free, but no algorithm automation.
- **Commonplace books** — Historical note-taking system. Combine with spaced review by annotating review dates.

### Digital Assistants
- **Notion templates** — Community-built spaced repetition templates in Notion. Less sophisticated than Anki but integrated with notes.
- **Obsidian + Spaced Repetition plugin** — Markdown-based note system with SRS plugin. Good for knowledge workers who live in Obsidian.
