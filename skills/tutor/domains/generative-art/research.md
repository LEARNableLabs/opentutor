# Generative and Computational Art — Research Summary

## Major Subtopics

### 1. Foundations of Generative Systems
- Randomness vs. pseudorandomness
- Perlin noise and coherent noise functions
- Autonomous systems and emergence
- Rule-based design
- Parametric design

### 2. Algorithmic Pattern & Form
- Grid systems and tessellations
- Recursion and fractals
- Symmetry operations
- Space-filling curves
- Modular composition

### 3. Motion & Time-Based Work
- Animation principles for code
- Particle systems
- Physics simulation (forces, springs)
- Flow fields
- Feedback loops and decay

### 4. Color Theory for Algorithms
- Computational color spaces (RGB, HSL, LAB)
- Palette generation algorithms
- Gradients and interpolation
- Image processing and pixel manipulation

### 5. Advanced Techniques
- Autonomous agents and steering behaviors
- L-systems and plant generation
- Cellular automata
- Markov chains
- Signed distance fields

### 6. Practice & Context
- Generative art history (Vera Molnár, Harold Cohen, Manfred Mohr)
- Contemporary practitioners
- Plotting and physical output
- NFTs and digital art markets
- Long-form generative art

## Key Educational Sources

- **Processing Foundation** (processing.org) — original creative coding environment, extensive tutorials
- **p5.js** (p5js.org) — JavaScript port, beginner-friendly, browser-based
- **The Nature of Code** by Daniel Shiffman — foundational text on simulation and autonomous systems
- **The Coding Train** YouTube channel — extensive video tutorials on generative techniques
- **Generative Artistry** (generative-artistry.com) — step-by-step tutorials recreating classic algorithms
- **Tyler Hobbs' essays** — deep writing on algorithmic aesthetics and long-form generative work
- **Inconvergent** (Anders Hoff) — technical blog on differential growth, sand painting, etc.
- **Creative Applications Network** — showcase and technical breakdowns
- **OpenProcessing** — community platform with thousands of sketches to study

## Available Interactive Tools

- **p5.js Web Editor** (editor.p5js.org) — instant coding environment
- **OpenProcessing** (openprocessing.org) — sketch sharing and remixing
- **Shadertoy** (shadertoy.com) — fragment shader playground
- **Hydra** — live-coding video synth
- **TouchDesigner** — node-based visual programming
- **Cables.gl** — WebGL creative coding platform

## Academic Programs & Syllabi

- MIT Media Lab courses (PVCC, How to Make Almost Anything)

- Parsons School of Design — computational design courses
- UCLA Design Media Arts

## Key Concepts to Cover

At intermediate level, students should master:
- Control over randomness (seeded, constrained, weighted)
- Noise functions for natural motion
- Recursive thinking
- Vector math for simulation
- Color space manipulation
- Agent-based systems
- Performance optimization for real-time work
- Export for print/plot vs. screen

## Prerequisites Assumed

- Basic programming (variables, loops, functions, arrays)
- High school math (algebra, some trigonometry)
- Familiarity with coordinate systems
- Some exposure to creative coding tools (Processing or p5.js)
