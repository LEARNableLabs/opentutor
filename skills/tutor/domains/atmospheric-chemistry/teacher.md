# Atmospheric chemistry and air quality — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 10 lessons (38%)
- **real-world application challenges** — 5 lessons (19%)
- **Socratic questions** — 3 lessons (12%)
- **curated resource exploration** — 3 lessons (12%)
- **review and consolidation sessions** — 3 lessons (12%)

Primary format: concept-focused mini-lessons.
