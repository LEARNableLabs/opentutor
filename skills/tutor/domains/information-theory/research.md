# Information Theory — Research Summary

## Major Subtopics

1. **Foundations** — Entropy, mutual information, divergence measures, data processing inequality
2. **Source Coding** — Lossless compression, Kraft inequality, Huffman coding, arithmetic coding, Shannon's source coding theorem
3. **Channel Coding** — Channel capacity, Shannon's channel coding theorem, error detection and correction, binary symmetric channel
4. **Rate-Distortion Theory** — Lossy compression, scalar and vector quantization, Shannon's rate-distortion theorem
5. **Multi-User Information Theory** — Multiple access channels, broadcast channels, interference channels, Slepian-Wolf coding
6. **Advanced Topics** — Differential entropy, Gaussian channels, network information theory, applications to machine learning

## Key Educational Resources Found

### University Courses

- **MIT 6.441 Information Theory** (Spring 2016) — Complete lecture notes by Polyanskiy & Wu available via OpenCourseWare. Covers both classical and modern topics including finite blocklength theory.
  - URL: https://ocw.mit.edu/courses/6-441-information-theory-spring-2016/
  - Lecture notes PDF: https://ocw.mit.edu/courses/6-441-information-theory-spring-2016/resources/mit6_441s16_course_notes/

- **Stanford EE 376A Information Theory** — Lecture notes by Tsachy Weissman. First two-thirds on core concepts (entropy, mutual information, compression, communication), last third on applications to statistics.
  - URL: https://web.stanford.edu/class/ee376a/
  - Lecture notes PDF: https://web.stanford.edu/class/ee376a/files/scribes/lecture_notes.pdf

- **UMass COMPSCI 650 Applied Information Theory** — Application-focused course with practical examples
  - URL: https://people.cs.umass.edu/~arya/courses/650/CS650-2016.html

### Textbooks

- **Elements of Information Theory (2nd ed.)** by Thomas Cover and Joy Thomas — The canonical reference, rigorous treatment suitable for graduate students and advanced undergraduates
  - Amazon: https://www.amazon.com/Elements-Information-Theory-Telecommunications-Processing/dp/0471241954

- **Information Theory, Inference, and Learning Algorithms** by David MacKay — More accessible alternative with rich illustrations, 400+ exercises, applications to machine learning and Bayesian inference
  - Amazon: https://www.amazon.com/Information-Theory-Inference-Learning-Algorithms/dp/0521642981

### Video Lectures

- **David MacKay's Cambridge lectures** on Information Theory, Pattern Recognition, and Neural Networks — Available on YouTube, noted for being engaging and intuitive
  - Lecture 1: https://www.youtube.com/watch?v=BCiZc0n6COY

### Interactive Tools & Visualizations

- **Visual Information Theory** by Christopher Olah (colah's blog) — Comprehensive visual guide with interactive diagrams for entropy, cross-entropy, KL divergence
  - URL: https://colah.github.io/posts/2015-09-Visual-Information/

- **A Visual Introduction to Information Theory** (arXiv paper) — Visual, intuition-driven guide showing how entropy, mutual information, and channel capacity follow from basic probability
  - URL: https://arxiv.org/abs/2206.07867
  - HTML version: https://arxiv.org/html/2206.07867v3

- **Shannon Entropy Interactive Calculator** by TensorTonic — Interactive tool for learning entropy formula, calculating bits, exploring uniform distributions
  - URL: https://www.tensortonic.com/ml-math/information-theory/shannon-entropy

- **AllTheSystems Entropy Visualizer** — Interactive simulator for randomness, cryptographic strength, system noise
  - URL: https://allthesystems.com/entropy-visualizer-simulator/

- **Information Entropy Visualizer** by Constraint Theory — Signal vs noise visualization
  - URL: https://constraint-theory.superinstance.ai/simulators/entropy

- **Information Theory Fundamentals** by Nima Sarang — Covers entropy, cross-entropy, KL divergence, Jensen-Shannon divergence with examples
  - URL: https://nimasarang.com/blog/2024-08-24-information-theory/

## Key Researchers & Practitioners

- **Claude Shannon** — Founder of information theory (1948 paper "A Mathematical Theory of Communication")
- **Thomas Cover** — Co-author of canonical textbook, made fundamental contributions to universal portfolios and hypothesis testing
- **David MacKay** — Made information theory accessible, connected to inference and machine learning
- **Yury Polyanskiy** (MIT) — Modern finite blocklength theory
- **Tsachy Weissman** (Stanford) — Applications to statistics and machine learning
- **Christopher Olah** — Visual explanations for technical concepts

## Resource Quality Assessment

- **Excellent for intermediate learners**: MacKay's book and lectures (intuitive, visual, connected to applications), colah's visual guide
- **Best for depth and rigor**: Cover & Thomas textbook, MIT/Stanford lecture notes
- **Best for hands-on exploration**: Interactive entropy calculators, visual introduction paper
- **Best for self-study**: MIT OCW (complete materials including problem sets and solutions)
