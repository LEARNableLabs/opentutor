# Computer Vision — Research Summary

## Major Subtopics

1. **Image Formation & Representation** — pixels, color spaces, image transforms
2. **Image Processing & Filtering** — convolution, edge detection, smoothing, morphological operations
3. **Feature Detection & Description** — corners, blobs, SIFT, HOG, local invariant features
4. **Image Segmentation** — thresholding, clustering, superpixels, semantic segmentation
5. **Object Detection & Recognition** — sliding windows, region proposals, modern CNN-based detectors
6. **Deep Learning for Vision** — CNNs, transfer learning, architectures (ResNet, VGG, etc.)
7. **3D Vision** — camera models, stereo vision, structure from motion, depth estimation
8. **Motion & Video Analysis** — optical flow, tracking, action recognition
9. **Advanced Topics** — generative models, vision transformers, self-supervised learning

## Key Sources

## Student Level Considerations

At **intermediate level**, students should:
- Have programming experience (Python preferred)
- Understand linear algebra (matrices, vectors, eigenvalues)
- Know basic calculus (derivatives, gradients)
- Have exposure to basic machine learning concepts
- Be comfortable reading and implementing algorithms

The curriculum emphasizes:
- Balance between classical CV and deep learning approaches
- Hands-on implementation (OpenCV, PyTorch/TensorFlow)
- Intuition before formalism
- Real-world applications and projects
- Connection between mathematical foundations and practical tools
