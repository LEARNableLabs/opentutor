# Algorithmic and Generative Music — Resources

## Primary Sources (for lesson content)

### Textbooks and Reference Works
- **The Computer Music Tutorial** by Curtis Roads — comprehensive 1,200-page reference covering synthesis, composition, signal processing, and algorithmic techniques. The encyclopedia of computer music. Dense but authoritative.
- **Algorithmic Composition: Paradigms of Automated Music Generation** by Gerhard Nierhaus (Springer) — systematic survey of algorithmic methods from ancient techniques to modern AI. Academic but accessible.
- **The SuperCollider Book** edited by Wilson, Cottle, and Collins (MIT Press) — definitive guide to SuperCollider, with chapters on synthesis, composition, and algorithmic techniques. Essential for serious live coders.
- **Designing Sound** by Andy Farnell (MIT Press) — practical pure data (pd) approach to procedural audio. Focus on synthesis over composition, but crucial for understanding sound generation.
- **Electronic Music and Sound Design (Vol 1 & 2)** by Alessandro Cipriani and Maurizio Giri — Max/MSP-based, excellent for visual learners. Theory + practice.

### Online Courses
- **Kadenze: Introduction to Programming for Musicians and Digital Artists** — ChucK-based course by Ge Wang (creator of ChucK). Great for beginners. https://www.kadenze.com/courses/introduction-to-programming-for-musicians-and-digital-artists/info
- **Kadenze: Machine Learning for Musicians and Artists** — Rebecca Fiebrink's Wekinator-based course. ML approaches to generative music. https://www.kadenze.com/courses/machine-learning-for-musicians-and-artists/info
- **MIT OpenCourseWare: 21M.380 Music and Technology** — Contemporary history and aesthetics of computer music. Covers Xenakis, Cage, Eno, and modern approaches. https://ocw.mit.edu/
- **Coursera: Introduction to Ableton Live** — Includes generative techniques with Max for Live. https://www.coursera.org/learn/ableton-live
- **FutureLearn: Music Production in Ableton Live** — Berklee course with generative music modules. https://www.futurelearn.com/

### Academic Papers (Key Readings)
- **Iannis Xenakis: "Formalized Music: Thought and Mathematics in Composition"** — foundational text on stochastic composition. Dense but essential for understanding algorithmic formalism.
- **David Cope: "Experiments in Musical Intelligence (EMI)"** — how to algorithmically analyze and replicate compositional style. Controversial and fascinating.
- **Curtis Roads: "Microsound"** — granular synthesis and time-scale manipulation. Connects algorithmic thinking to sound design.
- **Nick Collins: "Algorithmic Composition Methods for Breakbeat Science"** — academic paper on live coding and breakbeat generation. Fun and rigorous.

### Interactive Tools and Playgrounds

#### Live Coding Environments
- **Sonic Pi** — beginner-friendly live coding with Ruby syntax. Built-in tutorials, great error messages. https://sonic-pi.net/
- **TidalCycles** — pattern-based live coding, powerful mini-notation for rhythm and melody. https://tidalcycles.org/
- **SuperCollider** — professional synthesis and live coding platform. Steep learning curve, immense power. https://supercollider.github.io/
- **Estuary** — browser-based collaborative live coding. Multiple languages. https://estuary.mcmaster.ca/
- **Hydra** — live coding for visuals (pairs well with audio live coding). https://hydra.ojack.xyz/

#### Visual Programming
- **Max/MSP** — industry-standard visual programming for music. Commercial but student licenses available. https://cycling74.com/products/max
- **Pure Data (Pd)** — open-source Max cousin. Free, cross-platform. https://puredata.info/
- **Reaktor** — Native Instruments' modular environment. More synthesis-focused. https://www.native-instruments.com/en/products/komplete/synths/reaktor-6/

#### Web-Based
- **Tone.js** — Web Audio API framework for interactive music. Great for JavaScript developers. https://tonejs.github.io/

- **Glitch** — online IDE for JavaScript projects. Good for sharing Tone.js experiments. https://glitch.com/

- **ChucK** — strongly-timed audio programming language. https://chuck.cs.princeton.edu/

## Unexpected Connections (Rabbit Holes)

### Cross-Disciplinary
- **Oulipo** — literary movement using constraints. See: "A Void" (novel without the letter 'e'). Musical parallel: write with only 3 notes. https://en.wikipedia.org/wiki/Oulipo
- **Information Theory** — Claude Shannon's work on entropy. How much "surprise" in a melody? Connection to compression. https://en.wikipedia.org/wiki/Information_theory
- **Fractal Geometry** — self-similarity at different scales. Mandelbrot set, Julia sets applied to music. http://paulbourke.net/fractals/
- **Cellular Automata** — Conway's Game of Life. Stephen Wolfram's "A New Kind of Science" applied to sound. https://playgameoflife.com/
- **Network Theory** — modeling chord progressions as graphs, analyzing song structure. https://en.wikipedia.org/wiki/Network_theory

### Artistic Movements
- **Fluxus** — 1960s art movement, performance scores, chance operations. Influenced computer music.
- **Minimalism** — Steve Reich, Terry Riley, Philip Glass. Repetition, gradual process, phase shifting. Algorithmic thinking without computers.
- **Musique Concrète** — Pierre Schaeffer, tape manipulation. Precursor to sampling and digital audio.
- **Drone Music** — La Monte Young, sustained tones, harmonic series. Generative systems for timbre exploration.

### Technical Deep Dives
- **Procedural Audio in Games** — No Man's Sky's generative soundtrack, adaptive music in games. https://www.youtube.com/watch?v=tMVlJH6hXOg
- **Sonification of Data** — turning climate data, network traffic, stock markets into sound. Not "music" but related techniques. https://en.wikipedia.org/wiki/Sonification
- **Microtonal Music** — breaking free of 12-tone equal temperament. Just intonation, Bohlen-Pierce scale. http://www.huygens-fokker.org/
- **Modular Synthesis** — Eurorack, hardware patching. Algorithmic thinking in physical domain. https://www.muffwiggler.com/

## How to Use These Resources

### For Daily Lessons
Each lesson links to 1-3 specific resources. Use those first. This file is a broader reference for deep dives and rabbit holes.

### For Exploration
Students should:
- Install at least one live coding tool (recommend Sonic Pi to start)
- Watch 2-3 performance videos (to understand the practice)
- Read one historical text (Xenakis or Cage for context)
- Browse one code repository (to see real implementations)

### For Projects
When designing final projects or explorations, students can:
- Choose a tool that fits their style (visual vs text, beginner vs advanced)
- Pick a technique to explore deeply (e.g., specialize in Markov chains)
- Find inspiring performances and analyze them
- Engage with online communities (TOPLAP, forums, Discord servers)

### Ongoing Learning
After completing this curriculum:
- Join TOPLAP or local Algorave communities
- Contribute to open-source tools
- Attend live coding meetups or performances
- Explore advanced topics: ML for music, procedural audio, networked performance
- Read research papers from ICMC, NIME, ICLC conferences
