# Information Retrieval and Search Engines — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 13 lessons (45%)
- **review and consolidation sessions** — 5 lessons (17%)
- **Socratic questions** — 4 lessons (14%)
- **teach-back exercises (student explains)** — 3 lessons (10%)
- **real-world application challenges** — 3 lessons (10%)
- **curated resource exploration** — 1 lessons (3%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 38% accessible (1-2), 38% standard (3), 24% challenging (4-5).

Difficulty peaks:
- Day 11: "Why is BM25 still used in production search engines?" (difficulty 4)
- Day 12: "Can we model search as 'what language generated this query'?" (difficulty 4)
- Day 13: "How do neural networks change the game for search?" (difficulty 4)
- Day 19: "How do you make search results respect diversity?" (difficulty 4)
- Day 22: "Why do links matter for ranking web pages?" (difficulty 4)

## Domain Hooks
This field covers information retrieval and search engines, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.

## Vocabulary
Key terms for this domain: information needs, query formulation, retrieval task taxonomy, boolean retrieval, inverted index, term-document matrix, tolerant retrieval, edit distance, wildcard queries, spelling correction, term frequency, document frequency, tf-idf, zipf's law, tokenization (and 84 more).
