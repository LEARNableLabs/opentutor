# Typography and Lettering — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **real-world application challenges** — 16 lessons (47%)
- **concept-focused mini-lessons** — 15 lessons (44%)
- **review and consolidation sessions** — 3 lessons (9%)

Primary format: real-world application challenges.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 38% accessible (1-2), 35% standard (3), 26% challenging (4-5).

Difficulty peaks:
- Day 7: "How do you kern letter pairs to achieve visual balance?" (difficulty 4)
- Day 11: "How do kerning, tracking, and leading work together?" (difficulty 4)
- Day 16: "What happens when hierarchy, grids, and spacing fail?" (difficulty 4)
- Day 19: "How do you pair serif and sans-serif typefaces effectively?" (difficulty 4)
- Day 25: "How do you space custom lettering optically?" (difficulty 4)

## Domain Hooks
This field covers typography and lettering, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.

## Vocabulary
Key terms for this domain: type anatomy, x-height, baseline, ascenders, descenders, aperture, counter, stroke, visual voice, typeface personality, mood, structural variation, historical classification, humanist, transitional (and 115 more).
