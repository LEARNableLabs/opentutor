# Typography and Lettering — Research Summary

## Major Subtopics

### 1. Type Anatomy and Classification
- Type anatomy (x-height, baseline, ascenders, descenders, aperture, counter, etc.)
- Classification systems (humanist, geometric, transitional, modern, slab serif, etc.)
- Historical evolution and context

### 2. Typographic Hierarchy and Layout
- Visual hierarchy techniques
- Grid systems and layout structures
- Alignment, proximity, and grouping
- White space and negative space

### 3. Spacing and Rhythm
- Kerning (letter spacing adjustments)
- Tracking (overall letter spacing)
- Leading (line spacing)
- Vertical rhythm and baseline grids

### 4. Type Pairing and Combinations
- Contrast principles
- Mood and voice matching
- Technical compatibility
- Multi-font systems

### 5. Hand Lettering Fundamentals
- Brush lettering techniques
- Skeleton forms and construction
- Spacing and composition for custom lettering
- Digitization workflows

### 6. Custom Type Design Basics
- Sketching and ideation
- Digital tools (Glyphs, FontLab, Robofont)
- Character set design
- Spacing and kerning in type design

### 7. Practical Application
- Responsive typography
- Accessibility considerations
- Print vs. digital typography
- Performance and web fonts

## Key Sources

### Primary Educational Resources
- **Thinking with Type** by Ellen Lupton — comprehensive introduction to typography fundamentals, well-suited for intermediate learners
- **The Elements of Typographic Style** by Robert Bringhurst — definitive reference on typographic principles and best practices
- **Practical Typography** by Matthew Butterick (https://practicaltypography.com/) — free online book covering typography for writers and designers
- **Typography.com** (https://www.typography.com/blog/) — educational articles and case studies from Hoefler&Co.
- **Fonts In Use** (https://fontsinuse.com/) — real-world typography examples and analysis

## Key Concepts for Intermediate Level

At intermediate level, students should move beyond tool mechanics and basic terminology toward:
- Understanding the *why* behind typographic decisions
- Developing a critical eye for spacing and rhythm
- Practical skills in type pairing and hierarchy
- Introduction to custom lettering and type design
- Real-world application in both print and digital contexts
