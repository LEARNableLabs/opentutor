# Programming Language Theory — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 12 lessons (41%)
- **Socratic questions** — 5 lessons (17%)
- **real-world application challenges** — 4 lessons (14%)
- **teach-back exercises (student explains)** — 3 lessons (10%)
- **review and consolidation sessions** — 3 lessons (10%)
- **curated resource exploration** — 2 lessons (7%)

Primary format: concept-focused mini-lessons.
