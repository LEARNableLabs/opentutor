# Operations Research — Optimization in Practice (Research Summary)

## Major Subtopics

### 1. Linear Programming & Simplex Method
Foundation of OR: formulating real-world problems as linear programs, solving with simplex, understanding solution geometry, sensitivity analysis.

### 2. Duality Theory
Economic interpretation of optimization, dual formulation, complementary slackness, shadow prices, practical implications for decision-making.

### 3. Integer & Mixed-Integer Programming
Discrete optimization, branch-and-bound, cutting planes, formulation tricks, real-world applications (scheduling, routing, allocation).

### 4. Network Optimization
Shortest path, max flow, min cost flow, assignment problems, transportation problems—special structure enables efficient algorithms.

### 5. Nonlinear Optimization
Gradient methods, convex optimization, KKT conditions, practical algorithms (gradient descent, Newton's method, interior-point methods).

### 6. Modeling & Software Tools
Formulation techniques, modeling languages (AMPL, GAMS, JuMP), solvers (CPLEX, Gurobi, GLPK), open-source tools (OR-Tools, PuLP, CVXPY).

### 7. Real-World Applications
Production planning, supply chain, logistics, finance (portfolio optimization), machine learning (SVM, regression), energy systems.

## Level Assessment

**Intermediate level** assumes:
- Prerequisites: linear algebra, basic calculus, programming fundamentals
- Focus: practical formulation and solving, less on theoretical proofs
- Goals: formulate real problems, use modern tools, understand algorithm intuition, interpret solutions
- Depth: understand how algorithms work (not just "black box"), but avoid deep complexity theory
