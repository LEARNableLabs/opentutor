# Polymer Science — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 12 lessons (46%)
- **real-world application challenges** — 4 lessons (15%)
- **Socratic questions** — 3 lessons (12%)
- **review and consolidation sessions** — 3 lessons (12%)
- **curated resource exploration** — 2 lessons (8%)
- **teach-back exercises (student explains)** — 2 lessons (8%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 27% accessible (1-2), 46% standard (3), 27% challenging (4-5).

Difficulty peaks:
- Day 8: "What if we want polymers with two different monomer types?" (difficulty 4)
- Day 9: "Can we build polymers with perfect control?" (difficulty 4)
- Day 12: "What happens when a polymer tries to crystallize?" (difficulty 4)
- Day 13: "How can we see polymer structure without seeing individual atoms?" (difficulty 4)
- Day 17: "Why does silly putty behave like both a solid and a liquid?" (difficulty 4)

## Domain Hooks
This field covers polymer science, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.

## Vocabulary
Key terms for this domain: macromolecules, repeat units, degree of polymerization, chain length, thermoplastics, thermosets, elastomers, crosslinking, molecular weight averages, polydispersity, number-average Mn, weight-average Mw, radical polymerization, initiation, propagation (and 84 more).
