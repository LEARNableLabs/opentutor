# Vexillology — Resources

## Primary Sources (for lesson content)

### Books
- **Good Flag, Bad Flag** (NAVA, 2006) — the 24-page pamphlet that codified modern flag design principles. Essential reading, available free at https://nava.org/good-flag-bad-flag/
- **The Art of the Flag** by Whitney Smith — comprehensive introduction to vexillology by the discipline's founder
- **Flags Through the Ages and Across the World** by Whitney Smith — visual encyclopedia with historical context
- **A Flag Worth Dying For** by Tim Marshall — geopolitics and flag symbolism, engaging narrative style
- **The Flag Book** by Lonely Planet — world flags with compact cultural explanations

### Online Databases
- **Flags of the World (FOTW)** — https://www.fotw.info/ — the most comprehensive flag database, includes construction sheets, historical variants, and sub-national flags
- **World Flag Database** — https://www.flagcolorcodes.com/ — searchable by color, symbol, pattern
- **Vexilla Mundi** — https://www.vexilla-mundi.com/ — high-quality flag images with precise color specifications
- **Flagpedia** — https://flagpedia.net/ — clean interface, good for quick reference

### Academic/Professional Organizations
- **North American Vexillological Association (NAVA)** — https://nava.org/ — journal, conferences, design surveys, educational resources
- **International Federation of Vexillological Associations** — https://fiav.org/ — coordinates global vexillology groups
- **r/vexillology** — https://www.reddit.com/r/vexillology/ — active community with 600K+ members, redesign exercises, feedback

## Interactive Tools

### Design Tools
- **FlagMaker Jr.** — https://flagmakerjr.stg7.net/ — browser-based flag designer, no install needed, good for beginners
- **Tennessine Flag Designer** — https://tennessine.co.uk/flags/ — more advanced vector-based tool
- **FlagWaver** — https://krikienoid.github.io/flagwaver/ — 3D flag simulator, upload designs to see them wave realistically
- **Scrontch's Flag Designer** — https://flag-designer.appspot.com/ — simple geometric flag creator

### Analysis Tools
- **Flagvisualizer** — compare flags side-by-side by color, symbol
- **Flag Color Extractor** — analyze color palettes from flag images
- **Flag Similarity Search** — find flags visually similar to a given design (helps avoid duplication)

### Databases & Explorers
- **CIA World Factbook Flags** — https://www.cia.gov/the-world-factbook/ — official flags with downloadable images
- **Emoji Flag Reference** — https://emojipedia.org/flags/ — see how flags render as emoji across platforms
- **Historical Flag Timeline** — interactive timeline of flag evolution by country

## Unexpected Connections (cross-discipline links for wild cards)

### Mathematics
- **Nepal's flag construction** — 24-step geometric proof defining the world's only non-rectangular national flag
- **Golden ratio in flags** — Togo (1:1.618), aesthetic proportion theory
- **Symmetry groups** — flags as examples of rotational/reflectional symmetry

### Psychology
- **Color perception and flag recognition** — how color-blind individuals see flags differently
- **Gestalt principles in flags** — closure, figure-ground, proximity in flag composition
- **National identity formation** — flags as symbols that shape collective psychology

### Semiotics
- **Barthes's *Mythologies*** — flags as second-order signifiers
- **Peirce's triadic model** — icon/index/symbol in flag elements
- **Derrida on presence/absence** — what flags include vs exclude

### Politics & International Law
- **Law of the Sea** — maritime flag regulations (national ensigns, courtesy flags)
- **Olympic flag protocols** — IOC rules on flag display
- **Diplomatic flag precedence** — UN/embassy flag ordering rules

### Anthropology
- **Indigenous flag traditions** — Maori flags, First Nations flags, Aboriginal Australian flags
- **Tribal vexillology** — non-state group identities expressed through flags
- **Flag burning as speech** — cross-cultural attitudes toward flag desecration

### Computer Science
- **Unicode emoji politics** — how ISO/Unicode Consortium handle disputed territories (Taiwan, Catalonia, etc.)
- **SVG optimization** — balancing file size with flag detail for web use
- **Procedural flag generation** — algorithms for creating novel flag designs

### Art & Design
- **Bauhaus and flag design** — geometric abstraction principles
- **Suprematism** — Malevich's influence on bold geometric symbolism
- **Corporate logos as flags** — Apple, Nike, McDonald's following vexillological principles

### Linguistics
- **Esperanto flag** — designed for a constructed language movement
- **Klingon flag** — fictional vexillology in Star Trek
- **Emoji as international language** — flag emoji transcending text
