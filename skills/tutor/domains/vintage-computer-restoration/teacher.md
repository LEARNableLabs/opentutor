# Vintage Computer Restoration — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 8 lessons (29%)
- **Socratic questions** — 6 lessons (21%)
- **real-world application challenges** — 5 lessons (18%)
- **teach-back exercises (student explains)** — 3 lessons (11%)
- **review and consolidation sessions** — 3 lessons (11%)
- **curated resource exploration** — 3 lessons (11%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, code repositories. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 43% accessible (1-2), 36% standard (3), 21% challenging (4-5).

Difficulty peaks:
- Day 8: "Can you bring this Commodore 64 power brick back from the dead?" (difficulty 4)
- Day 11: "How do you chase a broken trace without the schematics?" (difficulty 4)
- Day 13: "What if the BIOS ROM is corrupted?" (difficulty 4)
- Day 18: "How do you fix a rolling picture or missing colors?" (difficulty 4)
- Day 24: "Why is the Amiga's capacitor plague so notorious?" (difficulty 4)

## Domain Hooks
This field covers vintage computer restoration, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.
