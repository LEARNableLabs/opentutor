# Behavioral Economics — Concept Map

## Core Concepts (in learning order)

1. **Bounded rationality** — humans use cognitive shortcuts instead of optimizing. Foundational to everything.
2. **Dual-process theory** — System 1 (fast, intuitive) vs System 2 (slow, deliberate). Depends on: bounded rationality
3. **Heuristics** — mental shortcuts (availability, representativeness, anchoring). Depends on: dual-process theory
4. **Cognitive biases** — systematic deviations from rational judgment. Depends on: heuristics
5. **Prospect theory** — how people evaluate gains and losses asymmetrically. Depends on: cognitive biases
6. **Loss aversion** — losses loom larger than gains. Depends on: prospect theory
7. **Framing effects** — how presentation changes decisions. Depends on: prospect theory
8. **Nudge theory** — designing choice architecture to guide better decisions. Depends on: all above

## Dependencies

- **Prospect theory** requires understanding **heuristics** and **cognitive biases** because it explains the systematic patterns behind biased decisions
- **Nudge theory** builds on **all prior concepts** because effective nudges exploit specific biases and heuristics

## Prerequisite Topics

- Basic probability — needed for understanding base rate neglect and statistical reasoning errors
- Introductory economics — needed for understanding departures from rational agent models
