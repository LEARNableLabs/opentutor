# Calligraphy — Western, Arabic, and East Asian traditions — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 8 lessons (31%)
- **real-world application challenges** — 5 lessons (19%)
- **teach-back exercises (student explains)** — 4 lessons (15%)
- **Socratic questions** — 3 lessons (12%)
- **review and consolidation sessions** — 3 lessons (12%)
- **curated resource exploration** — 3 lessons (12%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 46% accessible (1-2), 35% standard (3), 19% challenging (4-5).

Difficulty peaks:
- Day 9: "How does pressure create the thick-and-thin of Copperplate?" (difficulty 4)
- Day 15: "Why is Thuluth considered monumental?" (difficulty 4)
- Day 16: "How do letters stack and mirror in composition?" (difficulty 4)
- Day 19: "What is the 'bone method' in brush strokes?" (difficulty 4)
- Day 26: "Can you design a multi-script composition?" (difficulty 4)

## Domain Hooks
This field covers calligraphy — western, arabic, and east asian traditions, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.
