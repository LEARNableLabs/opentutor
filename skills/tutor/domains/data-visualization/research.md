# Information Design and Data Visualization — Research Summary

## Major Subtopics

### 1. Visual Perception and Cognition
- Pre-attentive processing and visual encoding
- Color theory and perception (including accessibility)
- Gestalt principles in visualization
- Visual hierarchy and cognitive load

### 2. Data Types and Encoding
- Quantitative, categorical, temporal, spatial, network data
- Visual encoding channels (position, length, angle, area, color, etc.)
- Marks and channels framework
- Data transformation and aggregation

### 3. Chart Types and When to Use Them
- Comparison charts (bar, column, dot plots)
- Distribution visualization (histograms, density plots, box plots)
- Part-to-whole (pie, treemap, stacked bars)
- Correlation and relationships (scatter, parallel coordinates)
- Time series and temporal patterns
- Geographic and spatial visualization
- Network and hierarchical data

### 4. Design Principles
- Tufte's principles: data-ink ratio, chartjunk, lie factor
- Clarity vs. engagement tradeoffs
- Accessibility (color blindness, screen readers, WCAG)
- Responsive and mobile-first design

### 5. Narrative and Storytelling
- Exploratory vs. explanatory visualization
- Narrative structures and flow
- Annotation and highlighting
- Context and comparison

### 6. Interactivity and Tools
- Interaction patterns (filter, zoom, drill-down, brushing/linking)
- Dashboard design
- Web technologies: D3.js, Observable, Vega-Lite
- BI tools: Tableau, Power BI
- Programming: Python (matplotlib, seaborn, plotly), R (ggplot2)

### 7. Ethics and Best Practices
- Misleading visualizations and manipulation
- Uncertainty representation
- Privacy and data aggregation
- Citation and source transparency

## Notes for Intermediate Level

This curriculum assumes:
- Basic familiarity with at least one programming language or visualization tool
- Understanding of basic statistics (mean, median, distribution)
- Exposure to common chart types (bar, line, scatter)

Focus areas for intermediate:
- Deep understanding of WHY certain encodings work better than others (perception)
- Practical experience building visualizations with real tools
- Critical analysis of existing visualizations
- Storytelling and communication, not just chart-making
- Hands-on projects with real datasets
