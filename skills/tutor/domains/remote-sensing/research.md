# Remote Sensing and Satellite Imagery — Research Summary

## Major Subtopics

### 1. Physical Foundations
- Electromagnetic radiation and the EM spectrum
- Energy-matter interactions (reflection, absorption, emission)
- Atmospheric effects and radiative transfer
- Spectral signatures of materials

### 2. Sensor Systems and Platforms
- Passive vs. active sensors
- Multispectral, hyperspectral, and panchromatic imaging
- Synthetic Aperture Radar (SAR) and LiDAR
- Satellite orbits (geostationary vs. sun-synchronous)
- Major platforms: Landsat, Sentinel, MODIS, Terra/Aqua

### 3. Image Characteristics and Quality
- Spatial, spectral, temporal, and radiometric resolution
- Scale and resolution tradeoffs
- Image distortions and artifacts
- Signal-to-noise ratio

### 4. Image Processing and Correction
- Radiometric calibration
- Atmospheric correction (dark object subtraction, FLAASH, etc.)
- Geometric correction and orthorectification
- Image enhancement and filtering

### 5. Analysis and Classification
- Supervised vs. unsupervised classification
- Spectral indices (NDVI, NDWI, etc.)
- Change detection methods
- Object-based image analysis
- Machine learning approaches (Random Forest, neural networks)

### 6. Applications
- Land use and land cover mapping
- Agriculture and food security
- Climate and environmental monitoring
- Disaster response and hazard mapping
- Urban planning
- Ocean and coastal monitoring

  - https://appliedsciences.nasa.gov/what-we-do/capacity-building/arset
- **ESA Earth Observation Portal** — comprehensive sensor database and educational materials
  - https://earth.esa.int/eogateway/
- **USGS Landsat Missions** — historical archive and educational resources
  - https://www.usgs.gov/landsat-missions
- **Copernicus Open Access Hub** — Sentinel data and documentation
  - https://scihub.copernicus.eu/

### Online Courses and Tutorials
- **Google Earth Engine Tutorials** — hands-on planetary-scale analysis
  - https://developers.google.com/earth-engine/tutorials
- **QGIS Training Manual** — open-source GIS with remote sensing modules
  - https://docs.qgis.org/latest/en/docs/training_manual/
- **Sentinel Hub EO Browser** — interactive exploration of satellite imagery
  - https://apps.sentinel-hub.com/eo-browser/

### Software and Tools
- **QGIS** — open-source GIS with remote sensing plugins (Semi-Automatic Classification Plugin)
- **Google Earth Engine** — cloud-based planetary analysis platform
- **SNAP (Sentinel Application Platform)** — ESA's free processing toolbox
- **GDAL** — geospatial data abstraction library (command-line)
- **Python libraries**: rasterio, geopandas, xarray, earthpy

### Interactive Visualizations
- **NASA Worldview** — near real-time satellite imagery viewer
  - https://worldview.earthdata.nasa.gov/
- **Sentinel Playground** — Sentinel-2 imagery with custom band combinations
  - https://www.sentinel-hub.com/explore/sentinelplayground/

## Student Level Assumptions (Intermediate)

**Prerequisites needed:**
- Basic physics (energy, waves, electromagnetic radiation)
- Elementary statistics (means, distributions, correlation)
- Basic programming (any language, for processing tasks)
- Familiarity with GIS concepts (layers, projections, coordinate systems)

**What intermediate means for this topic:**
- Can handle mathematical formulations without full derivations
- Ready to work with real datasets and processing workflows
- Interested in both theory and practical applications
- Can engage with scientific literature (but not research-level papers)

**Depth and pace:**
- Focus on understanding how things work, not just what they are
- Include hands-on examples and real sensor data
- Build from passive optical to active radar systems
- Emphasize decision-making: which sensor for which application?
