# Remote Sensing and Satellite Imagery — Resources

## Primary Sources (for lesson content)

### Comprehensive References

- **NASA ARSET (Applied Remote Sensing Training)**
  - Free online training modules covering fundamentals through advanced applications
  - Self-paced and instructor-led webinars
  - Covers Landsat, MODIS, VIIRS, Sentinel, and more
  - Certificate programs available
  - https://appliedsciences.nasa.gov/what-we-do/capacity-building/arset

- **ESA Earth Observation Gateway**
  - Complete database of Earth observation sensors and missions
  - Detailed technical specifications for Sentinel, Envisat, and other ESA missions
  - Educational materials and tutorials
  - https://earth.esa.int/eogateway/

- **USGS Landsat Missions**
  - Historical archive dating to 1972
  - Comprehensive documentation on sensors, processing levels, data formats
  - Educational resources and case studies
  - https://www.usgs.gov/landsat-missions

- **NASA Earthdata**
  - Portal to NASA Earth science data
  - Background articles on remote sensing fundamentals
  - Data access tutorials
  - https://www.earthdata.nasa.gov/

### Textbooks and Course Materials

- **"Remote Sensing of the Environment" by John R. Jensen**
  - Comprehensive intermediate-level textbook
  - Covers physical principles, sensors, processing, and applications
  - Used in many university courses

- **"Remote Sensing and Image Interpretation" by Lillesand, Kiefer, and Chipman**
  - Classic text, accessible to intermediate learners
  - Strong on aerial photography and photogrammetry background
  - Excellent visual examples

- **MIT OpenCourseWare — Introduction to Remote Sensing**
  - Free lecture notes, assignments, and exams
  - https://ocw.mit.edu/

- **Penn State GEOG 480/580: Introduction to Remote Sensing**
  - Free online course materials
  - Practical labs using ENVI and other tools
  - https://www.e-education.psu.edu/geog480/

### Software and Tools

#### Free and Open Source

- **QGIS** — open-source GIS with remote sensing plugins
  - Semi-Automatic Classification Plugin (SCP) for supervised/unsupervised classification
  - Raster analysis tools
  - https://qgis.org/

- **SNAP (Sentinel Application Platform)** — ESA's free processing toolbox
  - Sentinel-1, Sentinel-2, Sentinel-3 processing
  - Atmospheric correction (Sen2Cor)
  - SAR processing
  - https://step.esa.int/main/toolboxes/snap/

- **Google Earth Engine** — cloud-based planetary analysis
  - JavaScript and Python APIs
  - Petabytes of satellite data
  - Free for research and education
  - https://earthengine.google.com/

- **GDAL (Geospatial Data Abstraction Library)** — command-line utilities
  - Format conversion, reprojection, mosaicking

  - https://gdal.org/

## Unexpected Connections (Rabbit Holes)

### Cross-Disciplinary Applications

- **Medical Imaging** — MRI and CT scans use similar principles (EM radiation, spectral analysis, image processing)
  - "Your doctor's brain scan uses the same physics we're learning"

- **Astronomy** — Radio telescopes and infrared space telescopes (James Webb) are remote sensing instruments
  - "The Hubble Space Telescope looks outward; Landsat looks inward. Same principles, different targets."

- **Autonomous Vehicles** — LiDAR on self-driving cars is the same technology as airborne LiDAR
  - "Tesla's cameras + radar = multi-sensor fusion, just like we combine optical + SAR"

- **Smartphone Photography** — Computational photography (HDR, portrait mode) uses multi-spectral fusion
  - "Your iPhone's night mode combines multiple exposures — that's image compositing"

### Historical Context

- **Cold War Origins** — Landsat began as Corona spy satellites
  - Declassified Corona images now used for archaeology and historical land use

- **Environmental Movement** — "Earthrise" photo (1968) catalyzed environmental awareness
  - Remote sensing as a tool for planetary stewardship

- **Climate Change Documentation** — Satellite records are key evidence for warming, ice loss, sea level rise
  - IPCC reports rely heavily on remote sensing data

### Art and Culture

- **"Overview Effect"** — Astronauts report profound perspective shift seeing Earth from space
  - Satellite imagery democratizes this view

- **Satellite Art** — Artists use satellite data (e.g., Benjamin Grant's "Daily Overview")
  - Remote sensing as aesthetic medium

- **Citizen Science** — Tomnod, Global Forest Watch, DigitalGlobe crowdsourcing
  - "You can help map disasters, find lost planes, monitor deforestation"

### Weird and Wonderful

- **Radar Archaeology** — SAR reveals Angkor Wat's full extent, lost cities in the Sahara
  - "Satellites find ancient civilizations buried under jungles and sand"

- **Ocean Mysteries** — Satellite altimetry maps seafloor topography (underwater mountains create gravity bumps)
  - "We've mapped Venus better than Earth's ocean floor — but satellites are changing that"

- **Night Lights** — VIIRS measures artificial lights at night → economic activity, electrification, disasters
  - "Cities glow from space; North Korea is dark; this reveals economic inequality"

- **Volcanic Eruptions** — InSAR detects volcano deformation months before eruptions
  - "Satellites predict eruptions by measuring ground swelling"

- **Space Junk** — Remote sensing monitors orbital debris
  - "We use satellites to track satellites"

## Learning Pathways Beyond This Curriculum

### If you want to go deeper into **physical principles**:
- Study radiative transfer modeling (MODTRAN, 6S)
- Take atmospheric physics and optics courses
- Read Schott's "Fundamentals of Radiative Transfer"

### If you want to go deeper into **data science and ML**:
- Learn Random Forest, convolutional neural networks (U-Net, DeepLab)
- Study time series analysis (Fourier, wavelets, phenology)
- Practice with Kaggle competitions (DeepGlobe, SpaceNet)

### If you want to go deeper into **SAR**:
- Study SAR interferometry (InSAR, DInSAR)
- Learn polarimetry (PolSAR)
- Use SNAP and ISCE (InSAR Scientific Computing Environment)

### If you want to go deeper into **big data platforms**:
- Master Google Earth Engine (advanced JavaScript/Python)
- Explore OpenDataCube, Pangeo, AWS Open Data
- Learn cloud-native geospatial (COGs, STAC, Zarr)

### If you want to go deeper into **specific applications**:
- Agriculture: precision agriculture, crop yield modeling
- Climate: carbon monitoring, ice sheet dynamics, sea level rise
- Disasters: flood mapping, wildfire detection, damage assessment
- Urban: heat islands, growth modeling, infrastructure monitoring
- Ecology: habitat mapping, species distribution, ecosystem health

## Where to Get Help

1. **Stuck on concepts?** — Reread relevant lesson, watch ARSET webinar, ask on GIS Stack Exchange
2. **Stuck on software?** — Check official docs first (QGIS, SNAP, GEE), then YouTube tutorials, then forums

4. **Want to dive deeper?** — Pick one rabbit hole from above and explore it for a week

## Final Note

Remote sensing is a **rapidly evolving field**. New satellites launch constantly, new algorithms emerge, new platforms appear. The fundamentals in this curriculum are stable, but the tools and data sources will change. Cultivate these habits:

- **Stay current**: follow NASA, ESA, USGS announcements
- **Experiment**: download new datasets, try new tools
- **Connect**: join communities, attend webinars, collaborate
- **Apply**: find a project that matters to you and use remote sensing to address it

The best way to learn remote sensing is to **do** remote sensing. These resources will support you — now go explore the planet from space.
