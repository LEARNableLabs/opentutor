# Measure Theory and Integration — Concept Map

## Core Concepts (in learning order)

1. **Sigma-algebras** — collections of sets closed under countable unions and complements; the domain of a measure
2. **Measures** — functions assigning non-negative "sizes" to sets in a sigma-algebra with countable additivity
3. **Outer measures** — preliminary measures defined on all subsets, used to construct measures via Carathéodory
4. **Lebesgue measure** — the canonical measure on R^n generalizing length/area/volume. Depends on: sigma-algebras, measures, outer measures
5. **Measurable functions** — functions preserving the sigma-algebra structure via inverse images. Depends on: sigma-algebras
6. **Simple functions** — finite linear combinations of indicator functions; building blocks for integration. Depends on: measurable functions
7. **Lebesgue integral** — integral constructed by measuring level sets rather than partitioning domain. Depends on: measures, simple functions
8. **Monotone Convergence Theorem (MCT)** — limits and integrals commute for monotone sequences. Depends on: Lebesgue integral
9. **Fatou's Lemma** — liminf inequality for integrals. Depends on: Lebesgue integral
10. **Dominated Convergence Theorem (DCT)** — limits and integrals commute when dominated by integrable function. Depends on: Lebesgue integral, MCT
11. **Convergence modes** — pointwise, almost everywhere, in measure, in Lp; relationships between them. Depends on: measures, Lebesgue integral
12. **Product sigma-algebra** — sigma-algebra on product spaces generated by measurable rectangles. Depends on: sigma-algebras
13. **Product measure** — measure on product space satisfying multiplicativity on rectangles. Depends on: measures, product sigma-algebra
14. **Fubini-Tonelli theorems** — conditions for swapping order of iterated integrals. Depends on: product measure, Lebesgue integral
15. **Signed measures** — measures allowing negative values; relaxing positivity. Depends on: measures
16. **Hahn decomposition** — partitioning space into positive/negative sets for signed measure. Depends on: signed measures
17. **Jordan decomposition** — representing signed measure as difference of positive measures. Depends on: signed measures, Hahn decomposition
18. **Absolute continuity** — one measure vanishes wherever another does. Depends on: measures
19. **Radon-Nikodym theorem** — representing absolutely continuous measure as density/integral. Depends on: absolute continuity, Lebesgue integral
20. **Lp spaces** — function spaces with integral p-norms. Depends on: Lebesgue integral, measures
21. **Completeness of Lp (Riesz-Fischer)** — Lp spaces are complete metric spaces. Depends on: Lp spaces, DCT
22. **Lebesgue differentiation theorem** — relating differentiation and integration for absolutely continuous functions. Depends on: Lebesgue integral, Radon-Nikodym theorem

## Dependencies

### Foundational Chain
- **Measures require sigma-algebras** because we need a collection of sets that's closed under the operations measures care about (countable unions, complements)
- **Outer measures enable Lebesgue measure construction** via Carathéodory's extension theorem, which identifies which sets are "measurable"
- **Measurable functions require sigma-algebras** to define what it means to preserve structure (inverse images of measurable sets are measurable)

### Integration Theory Chain
- **Simple functions bridge measurability and integration** — they're easy to integrate (finite sums) but dense enough to approximate general functions
- **The three convergence theorems build on each other**: MCT is most basic (monotone sequences), Fatou's Lemma weakens to liminf, DCT adds integrability condition to get full limit
- **DCT is the workhorse** because it handles the most common case: bounded sequences of functions

### Product Structures
- **Product measure depends on product sigma-algebra** because measures must be defined on sigma-algebras
- **Fubini-Tonelli requires product measure** to relate iterated integrals to integral over product space
- **Tonelli (non-negative) is easier than Fubini (integrable)** — measurability is automatic for non-negative functions

### Signed Measures and Densities
- **Jordan decomposition requires Hahn decomposition** because you first split the space, then restrict the signed measure to each part
- **Radon-Nikodym requires absolute continuity** as the condition that enables density representation
- **Radon-Nikodym generalizes classical density functions** from calculus (relating area measure to Lebesgue measure)

### Function Spaces
- **Lp spaces require Lebesgue integral** because p-norms are defined as integrals of |f|^p
- **Completeness of Lp requires DCT** for the key step in proving Cauchy sequences converge
- **Lebesgue differentiation connects back to Radon-Nikodym** via absolutely continuous functions

## Critical Bottlenecks

1. **Sigma-algebras** — students must internalize why we need this structure (countable operations only, not all subsets)
2. **Countable additivity** — the key property distinguishing measures from finitely additive set functions
3. **Measurable functions** — understanding the abstract definition (inverse images) vs intuition (mostly everything is measurable)
4. **DCT conditions** — recognizing when you have a dominating function is the art of using DCT
5. **Fubini hypotheses** — knowing when you can and can't swap integrals (integrability vs non-negativity)
6. **Absolute continuity vs continuity** — these are completely different concepts with confusing names

## Common Learning Paths

**Path 1: Measure → Integration → Convergence**
Sigma-algebras → Measures → Lebesgue measure → Measurable functions → Simple functions → Lebesgue integral → MCT → Fatou → DCT

**Path 2: Adding Structure**
Basic integration → Product measures → Fubini → Signed measures → Radon-Nikodym → Lp spaces → Differentiation

**Path 3: Applications-First** (not used in this curriculum)
Start with Lebesgue integration, motivate measure theory retroactively — faster but less rigorous

This curriculum follows **Path 1 then Path 2**: solid foundations before adding structure.

## Prerequisite Topics (External)

- **Real analysis** — needed for: convergence concepts, epsilon-delta arguments, supremum/infimum
- **Point-set topology** — needed for: Borel sigma-algebra, continuous functions as measurable functions
- **Metric spaces** — needed for: Lp spaces as metric spaces, completeness
- **Linear algebra** — needed for: understanding function spaces as vector spaces, Lp as normed spaces
- **Undergraduate integration (Riemann)** — needed for: motivation, comparing Lebesgue to Riemann
