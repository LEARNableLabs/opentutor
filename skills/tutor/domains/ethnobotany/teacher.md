# Ethnobotany — plants and human cultures — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **Socratic questions** — 8 lessons (26%)
- **concept-focused mini-lessons** — 7 lessons (23%)
- **real-world application challenges** — 6 lessons (19%)
- **teach-back exercises (student explains)** — 4 lessons (13%)
- **review and consolidation sessions** — 4 lessons (13%)
- **curated resource exploration** — 2 lessons (6%)

Primary format: Socratic questions.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Gentle ramp — heavily front-loaded with accessible material before increasing complexity.

Distribution: 58% accessible (1-2), 32% standard (3), 10% challenging (4-5).

Difficulty peaks:
- Day 16: "How do we test if a traditional remedy actually works?" (difficulty 4)
- Day 18: "Explain how you would investigate a healer's claim about a new plant medicine" (difficulty 4)
- Day 30: "How can ethnobotany address biopiracy and promote benefit sharing?" (difficulty 4)

## Domain Hooks
This field covers ethnobotany — plants and human cultures, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.
