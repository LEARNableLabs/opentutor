# Resources — Logic from Aristotle to Gödel

## Primary Interactive Tools

### 1. Natural Deduction Proof Editor
**URL**: https://proofs.openlogicproject.org  
**Type**: Interactive proof checker  
**Description**: Fitch-style proof editor for propositional and first-order logic. Provides immediate feedback on proof steps.  
**When to use**: Lessons 7-14 (proof construction)  
**Features**: Natural deduction rules, step-by-step validation, export proofs

### 2. Logictools
**URL**: https://logictools.org  
**Type**: First-order logic toolkit  
**Description**: Browser-based FOL tools (runs via Wasm). Translation, model checking, proof search.  
**When to use**: Lessons 8-11 (translation and formalization)  
**Features**: Syntax checking, model visualization, automated proof search

### 3. LogicProof
**URL**: See arxiv.org/abs/2607.04321 for paper  
**Type**: Web-based theorem prover  
**Description**: Supports natural deduction and sequent calculus. More advanced than basic proof editors.  
**When to use**: Lessons 9-14 (advanced proof construction)  
**Features**: Multiple proof systems, export to LaTeX

### 4. The Logic Machine
**URL**: https://logic.tamu.edu  
**Type**: Proof checker with pedagogical hints  
**Description**: Daemon proof checker that provides hints when students get stuck.  
**When to use**: Lessons 7-11 (learning proof construction)  
**Features**: Hint system, multiple logic types, classroom integration

## Textbooks and Open Educational Resources

### Foundational Texts

#### "Incompleteness and Computability: An Open Introduction to Gödel's Theorems"
**URL**: https://ic.openlogicproject.org  
**Type**: Open textbook  
**Modules**: Completeness, incompleteness, computability  
**Best for**: Lessons 13-21 (Gödel's theorems and aftermath)  
**License**: CC BY

#### "A Course in Mathematical Logic for Mathematicians" by Yu. I. Manin
**Type**: Graduate textbook  
**Publisher**: Springer  
**Best for**: Lessons 13-18 (formal systems, completeness, incompleteness)  
**Note**: Rigorous but accessible to motivated undergraduates

#### Open Logic Project
**URL**: https://openlogicproject.org  
**Type**: Modular open-source textbook  
**Coverage**: Propositional logic, FOL, set theory, computability, incompleteness  
**Best for**: All lessons (comprehensive reference)  
**License**: CC BY

### Historical and Survey Texts

#### "History of Logic from Aristotle to Gödel"
**URL**: https://historyoflogic.com  
**Type**: Online resource with extensive bibliography  
**Coverage**: Ancient logic through 20th century  
**Best for**: Lessons 1-6, 12, 22-24 (historical context)  
**Features**: Timeline, key figures, philosophical debates

#### "Handbook of the History of Logic" (multiple volumes)
**Type**: Academic reference series  
**Publisher**: Elsevier  
**Coverage**: Ancient logic, medieval logic, modern logic, computability  
**Best for**: Deep dives into historical periods  
**Note**: Available in university libraries

## Recommended Learning Path Through Resources

1. **Lessons 1-6**: History of Logic website, Open Logic Project (propositional logic chapters)
2. **Lessons 7-11**: Natural Deduction Proof Editor, Logictools, MIT OCW notes
3. **Lessons 12-14**: Computational Logic lecture notes, Open Logic Project (formal systems)
4. **Lessons 15-19**: "Incompleteness and Computability" textbook, MIT Theory of Computation
5. **Lessons 20-24**: Handbook of History of Logic, Stanford Encyclopedia, synthesis articles

## Notes on Resource Quality

- **Open Logic Project** is the gold standard for free, high-quality logic education
- **Interactive proof tools** are essential — don't skip them
- **MIT OCW** provides rigorous, university-level treatment
- **History of Logic website** is excellent for context and motivation
- **Avoid**: "Gödel, Escher, Bach" as a primary textbook (fun but digressive; use as supplement)
