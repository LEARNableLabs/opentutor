# Logic — from Aristotle to Gödel — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **Socratic questions** — 7 lessons (29%)
- **concept-focused mini-lessons** — 6 lessons (25%)
- **real-world application challenges** — 4 lessons (17%)
- **review and consolidation sessions** — 4 lessons (17%)
- **teach-back exercises (student explains)** — 3 lessons (13%)

Primary format: Socratic questions.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 33% accessible (1-2), 29% standard (3), 38% challenging (4-5).

Difficulty peaks:
- Day 9: "What is a formal proof, really?" (difficulty 4)
- Day 13: "What does it mean for a formal system to be 'complete'?" (difficulty 4)
- Day 14: "Can you design a formal system for basic arithmetic?" (difficulty 4)
- Day 15: "What if truth is bigger than proof?" (difficulty 4)
- Day 16: "How can a sentence talk about itself?" (difficulty 5)

## Domain Hooks
This field covers logic — from aristotle to gödel, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.
