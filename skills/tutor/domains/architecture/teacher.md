# Architecture — space, form, and meaning — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 9 lessons (36%)
- **review and consolidation sessions** — 4 lessons (16%)
- **real-world application challenges** — 3 lessons (12%)
- **Socratic questions** — 3 lessons (12%)
- **teach-back exercises (student explains)** — 3 lessons (12%)
- **curated resource exploration** — 3 lessons (12%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 36% accessible (1-2), 40% standard (3), 24% challenging (4-5).

Difficulty peaks:
- Day 10: "What can typology teach us?" (difficulty 4)
- Day 11: "How does structure become expression?" (difficulty 4)
- Day 16: "Can buildings function as sign systems?" (difficulty 4)
- Day 18: "What role does memory play in architectural experience?" (difficulty 4)
- Day 22: "What is phenomenology in architecture?" (difficulty 4)

## Domain Hooks
This field covers architecture — space, form, and meaning, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.
