# Social Network Analysis — Research Summary

## Major Subtopics

### 1. Graph Fundamentals
- Graph representation (adjacency matrices, edge lists)
- Directed vs. undirected networks
- Weighted vs. unweighted edges
- Bipartite and multipartite graphs

### 2. Centrality and Importance
- Degree centrality
- Betweenness centrality
- Closeness centrality
- Eigenvector centrality and PageRank
- Katz centrality

### 3. Network Structure
- Connected components
- Clustering coefficients
- Triadic closure and transitivity
- Small-world properties
- Scale-free networks and preferential attachment

### 4. Community Detection
- Modularity optimization
- Label propagation
- Hierarchical clustering
- Spectral methods
- Louvain algorithm

### 5. Network Models
- Erdős-Rényi random graphs
- Configuration model
- Barabási-Albert preferential attachment
- Watts-Strogatz small-world model
- Stochastic block models

### 6. Dynamic Networks
- Temporal networks
- Network evolution
- Link prediction
- Diffusion processes (information, disease)
- Cascading behavior

### 7. Applications
- Social media analysis
- Biological networks (protein interactions, neural networks)
- Citation networks and knowledge graphs
- Infrastructure networks (power grids, internet topology)
- Organizational networks

## Key Sources

## Pedagogical Notes

For intermediate level:
- Assume basic graph theory knowledge (nodes, edges, paths, cycles)
- Assume probability/statistics comfort (distributions, expectation, basic inference)
- Programming experience (Python preferred for tools)
- Build from intuitive examples to formal measures
- Emphasize real-world applications and interpretation
- Balance computational practice with theoretical understanding
- Use visualization extensively — networks are inherently visual
