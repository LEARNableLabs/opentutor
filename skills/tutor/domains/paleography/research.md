# Paleography Research Summary

## Major Subtopics

### Script Families
- **Insular scripts** (7th-9th c.) — Irish/Anglo-Saxon manuscripts, distinctive letterforms
- **Carolingian minuscule** (8th-12th c.) — standardized script from Charlemagne's reforms
- **Gothic scripts** (12th-15th c.) — multiple variants (textualis, rotunda, cursiva, bastarda)
- **Humanistic scripts** (15th c. onward) — Renaissance revival of Carolingian forms
- **Secretary hand** (15th-17th c.) — administrative/documentary scripts

### Core Skills
- **Letter identification** — recognizing individual forms across scripts and time periods
- **Abbreviations and suspensions** — medieval shorthand systems, common contractions
- **Dating manuscripts** — script features, decorative elements, material analysis
- **Transcription practice** — converting historical handwriting to modern text
- **Codicological context** — understanding the manuscript as physical object

### Key Challenges
- **Allographic variation** — same letter written multiple ways in one script
- **Contextual reading** — using word/phrase context when individual letters are ambiguous
- **Language barriers** — most medieval manuscripts in Latin, Old English, Anglo-Norman
- **Preservation issues** — faded ink, damaged parchment, later annotations

## Available Resources

### Digital Platforms
- **DigiPal** (Cambridge/KCL) — interactive paleography for Anglo-Saxon/Insular scripts
- **The National Archives** — extensive online paleography tutorials for English scripts 1500-1800
- **Medieval Manuscripts Blog** (British Library) — case studies, featured manuscripts
- **e-codices** (Switzerland) — high-resolution manuscript images with transcriptions
- **Parker on the Web** — Corpus Christi Parker Library manuscripts

### Textbooks & Reference
- Bischoff, *Latin Palaeography* — comprehensive reference for medieval Latin scripts
- Clemens & Graham, *Introduction to Manuscript Studies* — includes paleography chapters
- Derolez, *The Palaeography of Gothic Manuscript Books* — definitive Gothic script reference
- Parkes, *English Cursive Book Hands 1250-1500* — focused on English scripts
- Cappelli, *Dizionario di Abbreviature* — standard abbreviation dictionary

### Online Courses & Tools
- University of London online paleography courses (IOE)
- Oxford MSt in Medieval Studies paleography modules
- Latin Paleography course materials (various universities via open courseware)
- Transcription exercises from university special collections

## Learning Progression

**Intermediate level** assumes:
- Familiarity with medieval/early modern history
- Basic Latin (helpful but not required)
- Some exposure to manuscript images
- Interest in archival research or book history

**Focus areas for intermediate:**
- Move beyond letter-by-letter reading to fluent transcription
- Recognize script types and date manuscripts within 50-year windows
- Master common abbreviations and suspensions
- Understand regional variations and scribal practices
- Apply skills to real research questions (provenance, attribution, editing)
