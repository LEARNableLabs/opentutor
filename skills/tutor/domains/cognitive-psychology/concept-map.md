# Cognitive Psychology — Concept Map

## Core Concepts (in learning order)

1. **Information processing** — The mind as a computational system that transforms sensory input into behavioral output
2. **Mental representations** — Internal cognitive structures that stand for external reality. Depends on: information processing
3. **Experimental paradigms** — Methods for measuring invisible mental processes through behavior and brain activity
4. **Selective attention** — Filtering mechanism that determines what information enters awareness
5. **Filter theory** — Early vs. late selection models of attention. Depends on: selective attention
6. **Automatic processing** — Fast, effortless mental operations that occur without conscious control. Depends on: information processing
7. **Controlled processing** — Slow, effortful mental operations requiring conscious attention. Depends on: information processing, selective attention
8. **Divided attention** — Ability to process multiple streams of information simultaneously. Depends on: selective attention, automatic processing
9. **Attentional resources** — Limited capacity model of attention as a finite resource. Depends on: divided attention
10. **Inattentional blindness** — Failure to notice unexpected stimuli when attention is engaged elsewhere. Depends on: selective attention
11. **Executive attention** — Top-down control mechanisms for managing cognitive resources. Depends on: controlled processing, attentional resources
12. **Working memory** — Temporary storage system for active manipulation of information. Depends on: attention, information processing
13. **Baddeley's model** — Multi-component working memory architecture. Depends on: working memory
14. **Central executive** — Supervisory attention system controlling working memory. Depends on: Baddeley's model, executive attention
15. **Phonological loop** — Verbal/auditory short-term storage. Depends on: Baddeley's model
16. **Visuospatial sketchpad** — Visual/spatial short-term storage. Depends on: Baddeley's model
17. **Encoding** — Process of transforming perception into memory representation. Depends on: mental representations, attention
18. **Levels of processing** — Depth of encoding determines memory strength. Depends on: encoding
19. **Episodic memory** — Memory for personally experienced events. Depends on: encoding, mental representations
20. **Semantic memory** — Memory for general knowledge and facts. Depends on: encoding, mental representations
21. **Retrieval** — Process of accessing stored information. Depends on: encoding
22. **Reconstruction** — Memory as active rebuilding rather than playback. Depends on: retrieval
23. **Reconsolidation** — Updating of memories during retrieval. Depends on: retrieval, reconstruction
24. **Consolidation** — Stabilization of memory over time. Depends on: encoding
25. **Forgetting** — Loss of memory access over time. Depends on: retrieval
26. **Interference** — Competing memories disrupt retrieval. Depends on: forgetting, retrieval
27. **Framing effects** — Decision changes based on how options are presented. Depends on: mental representations
28. **Prospect theory** — People evaluate outcomes relative to reference points, not absolute values. Depends on: framing effects
29. **Loss aversion** — Losses loom larger than equivalent gains. Depends on: prospect theory
30. **Heuristics** — Mental shortcuts for quick judgments. Depends on: information processing
31. **Availability heuristic** — Judging frequency by ease of recall. Depends on: heuristics, retrieval
32. **Representativeness heuristic** — Judging probability by similarity to prototypes. Depends on: heuristics
33. **Anchoring** — Initial values bias subsequent estimates. Depends on: heuristics
34. **Dual-process theory** — Two systems of thinking with different speeds and effort. Depends on: automatic processing, controlled processing
35. **System 1** — Fast, intuitive, automatic thinking. Depends on: dual-process theory, automatic processing
36. **System 2** — Slow, deliberate, effortful thinking. Depends on: dual-process theory, controlled processing
37. **Bounded rationality** — Humans satisfice rather than optimize due to cognitive limits. Depends on: dual-process theory, attentional resources
38. **Cognitive architecture** — Overall structure and computational limits of the mind. Depends on: all prior concepts

## Dependencies

- **Baddeley's model requires understanding working memory** because it's a specific theoretical decomposition of working memory into subcomponents with different functions
- **Dual-process theory builds on automatic and controlled processing** because System 1/System 2 are essentially the same distinction applied to judgment and decision-making
- **Encoding failures depend on attention** because information not attended to cannot be properly encoded into memory
- **Availability heuristic requires retrieval mechanisms** because it depends on how easily examples come to mind
- **Executive attention and central executive are parallel concepts** in attention and memory domains respectively
- **Reconsolidation builds on both retrieval and reconstruction** because memories must be retrieved and actively reconstructed before being updated
- **Bounded rationality integrates attentional resources and dual-process theory** because cognitive limits explain why we satisfice instead of optimize

## Bottleneck Concepts

These concepts are critical gates that many later concepts depend on:

1. **Information processing** — Foundation for all cognitive psychology; without this framework, nothing else makes sense
2. **Attention as limited resource** — Explains both attention phenomena and memory encoding failures
3. **Mental representations** — Core to understanding memory, decision-making, and how the mind stands for the world
4. **Automatic vs. controlled processing** — Fundamental distinction that appears in attention, memory, and decision-making
5. **Dual-process theory** — Unifying framework connecting all three domains

## Mind-Blowing Moments

1. **Change blindness demonstrations** (Lesson 6) — Seeing how much we miss when not attending reveals the constructed nature of conscious experience
2. **Memory reconsolidation** (Lesson 13) — The revelation that remembering changes the memory itself destroys the "playback" metaphor most students hold
3. **Framing effects in expert decisions** (Lesson 17) — Watching professionals make opposite choices based purely on wording challenges beliefs about rationality
4. **Dual-process integration** (Lesson 27) — Realizing that attention, memory, and decision-making all reflect the same computational architecture
5. **The adaptive value of forgetting** (Lesson 15) — Reframing "failure" as feature inverts the student's mental model

## Common Misconceptions

1. **"Memory is like a video recorder"** — Actually it's reconstructive, not reproductive. Address in Lessons 13, 15
2. **"We can multitask effectively"** — Divided attention is task-switching, not parallel processing. Address in Lesson 5
3. **"Attention is all-or-nothing"** — It's graded and resource-based, not binary. Address in Lessons 3-7
4. **"Working memory is the same as short-term memory"** — Working memory includes active processing, not just storage. Address in Lesson 10
5. **"Biases are always bad"** — Heuristics are adaptive shortcuts; the question is when they fail. Address in Lessons 18-21
6. **"System 1 is dumb, System 2 is smart"** — Both are adaptive for different environments. Address in Lesson 20
7. **"Forgetting means the memory is gone"** — Often it's retrieval failure, not storage loss. Address in Lesson 15
8. **"Expert intuition is always reliable"** — Expertise helps in predictable environments, not chaotic ones. Address in Lesson 22

## Prerequisite Topics

- **Introduction to Psychology** — needed for familiarity with research methods, brain regions, basic terminology
- **Basic Statistics** — needed for understanding experimental designs, probability concepts in decision-making
- **Scientific Method** — needed for evaluating evidence, designing experiments, understanding control conditions

## Advanced Extensions (beyond this curriculum)

- **Computational cognitive modeling** — Formal mathematical models of cognitive processes
- **Cognitive neuroscience** — Neural implementation of cognitive functions
- **Clinical applications** — ADHD, amnesia, decision-making deficits
- **Individual differences** — Working memory capacity, cognitive styles, expertise
- **Developmental trajectories** — How attention, memory, and decision-making change across lifespan
