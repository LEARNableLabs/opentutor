# Cognitive Psychology — Resources

## Primary Sources (for lesson content)

### Textbooks

- **Baddeley, Eysenck, & Anderson — Memory** (3rd edition)
  - Authoritative comprehensive introduction to memory systems
  - Covers working memory, encoding, retrieval, forgetting, and applications
  - Perfect for intermediate students; accessible but rigorous
  - https://www.amazon.com/Memory-Alan-Baddeley/dp/1138326097

- **Baddeley — Essentials of Human Memory (Classic Edition)**
  - Written by the originator of the working memory model
  - Combines laboratory research with real-world case studies
  - Excellent for understanding the evolution of memory theory
  - https://www.amazon.com/Essentials-Classic-Psychology-Routledge-Editions/dp/1848721412

- **Baddeley — Working Memory (Oxford Psychology Series)**
  - Deep dive into the working memory model and its development over 20+ years
  - More advanced treatment of multi-component architecture
  - https://www.amazon.com/Working-Memory-Oxford-Psychology-Baddeley/dp/0198521332

- **Cognitive Psychology: A Student's Handbook**
  - Leading undergraduate textbook with comprehensive coverage
  - Co-authored by Baddeley and other top researchers
  - Covers all three domains: attention, memory, decision-making
  - https://hmk.am/wp-content/uploads/2021/11/Cognitive-Psychology_-A-Students-Handbook-PDFDrive.com-.pdf

### Academic Papers (foundational)

- **Baddeley, A. (2012). Working Memory: Theories, Models, and Controversies**
  - Science article summarizing the working memory model
  - https://www.nschwartz.yourweb.csuchico.edu/1.%20Working%20Memory%20-%20Theories%20and%20Models%20and%20Controversies.pdf

- **Baddeley & Hitch (1974) working memory model** — available via Internet Archive
  - https://archive.org/details/workingmemorytho0000badd

- **N-back tasks** — test working memory capacity

## Unexpected Cross-Discipline Connections

### To Behavioral Economics
- Kahneman's work bridges cognitive psychology and economics (Nobel Prize in Economics for a psychologist!)
- Prospect theory, loss aversion, and framing are now core to economics, public policy, and marketing
- Richard Thaler's "nudge" applies cognitive biases to choice architecture

### To AI & Computer Science
- Attention mechanisms in neural networks (Transformers) inspired by human selective attention
- Working memory models inform AI architectures (memory-augmented neural networks)
- Dual-process theory relates to System 1 (fast heuristics) vs. System 2 (slow deliberation) in AI planning

### To Human-Computer Interaction (HCI)
- Cognitive load theory drives UI/UX design
- Working memory limitations shape interface design (7±2 rule, chunking)
- Attention research informs notification design, multitasking interfaces

### To Neuroscience
- fMRI localizes cognitive functions (prefrontal cortex = working memory, hippocampus = episodic memory)
- Patient studies (H.M., Phineas Gage) reveal functional architecture
- Optogenetics and TMS allow causal manipulation of attention and memory

### To Law & Criminal Justice
- Eyewitness testimony research (Loftus) changed legal procedures
- False memory research impacts interrogation techniques
- Decision-making biases affect jury judgments, plea bargaining

### To Education
- Testing effect → retrieval practice beats re-reading
- Spaced repetition → distributed practice optimizes retention
- Cognitive load theory → instructional design principles

### To Clinical Psychology
- ADHD as attention dysregulation
- PTSD as failure of memory reconsolidation
- Depression linked to overgeneral autobiographical memory
- Anxiety and risk perception biases
