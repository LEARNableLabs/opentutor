# Cognitive Psychology — Research Summary

## Major Subtopics

Based on university course syllabi and educational resources, cognitive psychology covering memory, attention, and decision-making breaks into these major areas:

### 1. Foundations & Methods
- History of cognitive psychology
- Research methodologies (experimental, neuroimaging, computational modeling)
- Information processing framework

### 2. Attention
- Selective attention and filter theories
- Divided attention and automatic processing
- Executive attention and cognitive control
- Attention deficits and disorders

### 3. Memory Systems
- Working memory (Baddeley's model: central executive, phonological loop, visuospatial sketchpad)
- Long-term memory encoding and retrieval
- Episodic vs. semantic memory
- Memory consolidation and reconsolidation
- Forgetting and interference

### 4. Decision-Making & Judgment
- Heuristics and biases (Kahneman & Tversky)
- Prospect theory and framing effects
- Dual-process theory (System 1 vs. System 2)
- Rational vs. bounded rationality
- Risk perception and probability judgment

## Key Sources Found

### University Courses
- **MIT OpenCourseWare** — Introduction to Psychology (9.00SC) with full lecture videos by Prof. Gabrieli, including dedicated lectures on memory and cognitive neuroscience methods
- **Carnegie Mellon** — Cognitive Psychology (85-211) structured around Perception/Attention/Memory and higher cognition units
- **UC Berkeley Extension** — Cognitive psychology course covering decision-making processes, memory stages, and individual differences
- **UNC Chapel Hill** — Three-module structure: Attention & Perception, Learning & Memory, Higher Cognitive Function
- **METU** — Course with specific lecture notes on attention, working memory, long-term memory, and decision-making

### Key Textbooks
- **Baddeley, Eysenck, & Anderson — Memory** (authoritative comprehensive introduction)
- **Baddeley — Essentials of Human Memory** (working memory model originator)
- **Cognitive Psychology: A Student's Handbook** (leading undergraduate text)
- **Baddeley — Working Memory, Thought, and Action** (detailed model development)

### Video Lectures & Interactive Resources
- **MIT OCW Brain & Cognitive Sciences Computational Tutorial Series** — computational tutorials with lecture videos, slides, code, and datasets
- **MIT Introduction to Psychology lectures** — complete video series with Prof. John Gabrieli
- Multiple university lecture note repositories available through Studocu

### Key Researchers & Practitioners
- **Alan Baddeley** — working memory model
- **Daniel Kahneman** — judgment and decision-making, heuristics and biases, Nobel laureate
- **Amos Tversky** — prospect theory, cognitive biases
- **Michael Anderson** — memory and forgetting
- **Michael Eysenck** — cognitive psychology pedagogy

## Available Educational Resources

### Interactive Tools
- MIT computational tutorials with code and datasets for hands-on practice
- Experimental paradigms: Stroop task, visual search, working memory span tasks
- Decision-making simulations and probability judgment exercises

### Cross-Disciplinary Connections
- Behavioral economics (Kahneman's work bridges psychology and economics)
- Neuroscience (fMRI studies of attention and memory systems)
- Computer science (computational models of cognition, AI systems)
- Clinical psychology (attention disorders, memory impairments)
