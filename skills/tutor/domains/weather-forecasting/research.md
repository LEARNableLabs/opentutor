# Weather Forecasting Research Summary

## Topic Scope
Weather forecasting through cloud identification and pressure system analysis — practical observational meteorology for intermediate learners with basic science background.

## Major Subtopics

### 1. Cloud Classification & Interpretation
- 10 cloud genera (WMO International Cloud Atlas)
- Cloud species, varieties, and accessory features
- Vertical structure and atmospheric stability
- Cloud-based precipitation forecasting

### 2. Atmospheric Pressure & Circulation
- Pressure systems (highs, lows, ridges, troughs)
- Fronts (cold, warm, occluded, stationary)
- Pressure gradients and wind patterns
- Isobars and surface analysis

### 3. Observational Techniques
- Sky reading and pattern recognition
- Synoptic observation workflow
- Pressure tendency interpretation
- Multi-indicator synthesis

### 4. Short-term Forecasting
- 6-24 hour local forecasting
- Nowcasting techniques
- Rule-based forecasting systems
- Verification and skill assessment

## Key Educational Resources

### Primary References
- **NOAA JetStream** (https://www.weather.gov/jetstream/) — comprehensive weather education portal, excellent cloud galleries and pressure system tutorials
- **Met Office Learn About Weather** (https://www.metoffice.gov.uk/weather/learn-about) — UK perspective, strong on synoptic meteorology
- **WMO International Cloud Atlas** (https://cloudatlas.wmo.int/) — authoritative cloud classification reference with photos
- **CoCoRaHS Training** (https://www.cocorahs.org/Content.aspx?page=training) — citizen science observer training materials

### University Courses
- **Penn State METEO 3 (Introductory Meteorology)** — open courseware with modules on clouds and forecasting
- **MIT OCW 12.003 (Atmosphere, Ocean and Climate Dynamics)** — more advanced, good for physical foundations

### Interactive Tools
- **Windy.com** (https://www.windy.com/) — real-time pressure maps, model visualization
- **NOAA Aviation Weather Center** (https://aviationweather.gov/) — surface analysis charts, prognostic charts
- **Zoom Earth** (https://zoom.earth/) — satellite imagery with analysis overlays

### Video Series
- **NWS WFO Birmingham Cloud Spotter Training** (YouTube) — practical cloud identification
- **NOAA SciJinks** (https://scijinks.gov/) — engaging explainers for intermediate learners

## Pedagogical Considerations
- **Visual-heavy domain** — requires extensive photo/satellite examples
- **Pattern recognition skill** — needs spaced practice and real-world application
- **Intermediate level** — assumes basic atmospheric science (pressure, humidity, temperature) but teaches observational synthesis
- **Forecasting is probabilistic** — must emphasize uncertainty and verification
- **Regional variation** — examples should span climates where appropriate
- **Citizen science connection** — CoCoRaHS, CWOP, Skywarn provide engagement pathways

## Difficulty Progression
1. Foundation (lessons 1-7): Cloud classification, basic pressure concepts
2. Build (lessons 8-16): Fronts, synoptic patterns, multi-indicator analysis
3. Peak (lessons 17-22): Forecasting synthesis, rare phenomena, troubleshooting
4. Application (lessons 23-25): Real-world practice, verification, ongoing learning
