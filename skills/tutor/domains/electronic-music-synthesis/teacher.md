# Electronic Music Synthesis — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 10 lessons (31%)
- **real-world application challenges** — 8 lessons (25%)
- **Socratic questions** — 5 lessons (16%)
- **review and consolidation sessions** — 4 lessons (13%)
- **teach-back exercises (student explains)** — 3 lessons (9%)
- **curated resource exploration** — 2 lessons (6%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 34% accessible (1-2), 38% standard (3), 28% challenging (4-5).

Difficulty peaks:
- Day 12: "Can you resynthesize a real instrument?" (difficulty 4)
- Day 14: "Why does FM create those metallic bell sounds?" (difficulty 4)
- Day 16: "How do DX7 algorithms work?" (difficulty 4)
- Day 17: "Can you design a complex FM pad from scratch?" (difficulty 5)
- Day 21: "Can you hear the difference between time and frequency domain?" (difficulty 4)

## Domain Hooks
This field covers electronic music synthesis, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.

## Vocabulary
Key terms for this domain: signal flow, audio rate vs. control rate, oscillator-filter-amplifier chain, CV/gate paradigm, modulation sources, control voltage, patch cables, modulation routing, normalization, resonance, filter self-oscillation, Q factor, LFO routing, filter sweeps, amplitude modulation (and 82 more).
