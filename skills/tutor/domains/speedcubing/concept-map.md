# Speedcubing — Concept Map

## Core Concepts (in learning order)

1. **Cross Efficiency** — solving the first layer cross in 8 or fewer moves during inspection
2. **Inspection Strategy** — planning moves before touching the cube (15-second WCA limit)
3. **Cross Orientation** — choosing to solve cross on bottom vs. other orientations
4. **Color Neutrality** — ability to start solve from any color cross
5. **F2L (First Two Layers)** — simultaneously solving first two layers via corner-edge pairing. Depends on: Cross Efficiency
6. **Pair Recognition** — instantly identifying corner-edge pair locations and states. Depends on: F2L
7. **Intuitive F2L** — solving pairs through understanding rather than memorization. Depends on: F2L, Pair Recognition
8. **Algorithmic F2L** — memorized solutions for 41 standard F2L cases. Depends on: Intuitive F2L
9. **Slot Choice** — selecting which F2L slot to fill based on efficiency. Depends on: F2L
10. **OLL (Orientation of Last Layer)** — orienting all last layer pieces. Depends on: F2L
11. **2-Look OLL** — solving OLL in two algorithmic steps (edges then corners). Depends on: OLL
12. **Full OLL** — recognizing and solving all 57 OLL cases in one look. Depends on: 2-Look OLL
13. **PLL (Permutation of Last Layer)** — permuting all last layer pieces after orientation. Depends on: OLL
14. **2-Look PLL** — solving PLL in two steps (corners then edges). Depends on: PLL
15. **Full PLL** — recognizing and solving all 21 PLL cases in one look. Depends on: 2-Look PLL
16. **Finger Tricks** — efficient finger movements for executing algorithms quickly. Depends on: basic turning
17. **Turning Technique** — ergonomic cube manipulation minimizing wrist movement. Depends on: Finger Tricks
18. **Lookahead** — tracking next pieces while executing current moves to reduce pauses. Depends on: F2L, Algorithmic F2L
19. **TPS (Turns Per Second)** — raw turning speed metric. Depends on: Finger Tricks, Turning Technique
20. **Move Efficiency** — minimizing total move count for a solve. Depends on: Cross Efficiency, Intuitive F2L
21. **Algorithm Variants** — alternative fingertrick-optimized versions of algorithms. Depends on: Full OLL, Full PLL, Finger Tricks
22. **Solve Reconstruction** — analyzing recorded solves move-by-move for improvement. Depends on: all CFOP stages
23. **Alternative Methods** — understanding Roux, ZZ, Petrus, and other solving approaches. Depends on: CFOP foundation
24. **Practice Strategy** — structured training targeting specific weaknesses. Depends on: Solve Reconstruction
25. **Advanced F2L** — techniques like multislotting, VHLS, winter variation. Depends on: Full F2L mastery, Lookahead

## Dependencies

### Cross → F2L Transition
- **F2L requires efficient cross** because you need a stable foundation to build pairs on. An inefficient cross (>8 moves, bad edge placement) makes F2L pair recognition harder and wastes inspection time.
- **Color neutrality expands cross options** because it allows you to choose the most efficient cross regardless of starting orientation, often saving 2-3 moves.
- **Tracking first pair during cross** creates seamless transition to F2L, eliminating the first major pause.

### Intuitive → Algorithmic F2L
- **Intuitive F2L must precede algorithmic** because understanding why pair manipulation works prevents blind memorization and enables case adaptation when algorithms are forgotten.
- **Algorithmic F2L builds on intuitive foundation** by providing optimized move sequences for common cases, but the intuitive understanding remains critical for edge cases.

### OLL → PLL Dependency
- **PLL requires oriented last layer** because permutation algorithms assume all pieces are oriented correctly. Running PLL on unoriented pieces produces scrambled results.
- **2-look stages scaffold to 1-look mastery** because the conceptual split (edges vs. corners for OLL; corners vs. edges for PLL) makes pattern recognition manageable before learning full algorithm sets.

### Lookahead Bottleneck
- **Lookahead depends on algorithmic fluency** because you can't track next pieces while consciously thinking about current algorithm. Muscle memory for F2L, OLL, and PLL is prerequisite.
- **Lookahead is the primary speed multiplier** because it eliminates pauses between F2L pairs (often 0.5-2 seconds each) and between CFOP stages. TPS gains are limited; lookahead gains are unlimited.
- **Lookahead requires slow deliberate practice** because attempting it at full speed reinforces bad tracking habits.

### Finger Tricks → Speed
- **Finger tricks enable TPS** because wrist turning creates a hard ceiling around 3-4 TPS, while proper finger tricks allow 8+ TPS.
- **Algorithm variants optimize fingertricks** because the same logical algorithm can have radically different execution speeds depending on finger movement (e.g., R U R' U' vs. different orientations).

### Analysis → Improvement
- **Solve reconstruction reveals weaknesses** because it exposes exactly where time is lost: cross planning, F2L pauses, wrong algorithm choice, execution speed.
- **Practice strategy targets weaknesses** identified through reconstruction analysis. Blind practice without analysis creates plateaus.

## Prerequisite Topics

- **Basic Cube Solving** (beginner/LBL method) — needed for Cross, F2L foundation, notation understanding
- **Cube Notation** (F, R, U, L, D, B, M, x, y, z) — needed for all algorithmic learning
- **Spatial Reasoning** — needed for Pair Recognition, Lookahead, Color Neutrality
- **Muscle Memory Development** — needed for Finger Tricks, Algorithm Execution
- **Pattern Recognition** — needed for OLL, PLL, F2L case identification

## Learning Bottlenecks

1. **Cross Efficiency** — students often rush this, creating cascade of F2L inefficiency
2. **Intuitive F2L Understanding** — jumping to algorithms too early creates brittle knowledge
3. **Lookahead Development** — most critical skill, hardest to learn, requires sustained deliberate practice
4. **Algorithm Memorization** (57 OLL + 21 PLL) — intimidating volume; requires systematic spaced repetition
5. **Slow Practice Discipline** — counterintuitive but essential for lookahead; students resist slowing down
