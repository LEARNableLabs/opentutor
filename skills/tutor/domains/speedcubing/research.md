# Speedcubing — Research Summary

## Major Subtopics

### 1. Speed Methods
- **CFOP (Fridrich Method)** — dominant method used by most world-class speedcubers (Cross, F2L, OLL, PLL)
- **Roux Method** — alternative method emphasizing block building and fewer rotations
- **ZZ Method** — edge orientation first, then block building
- **Petrus Method** — intuitive block building approach

### 2. Core Techniques
- **Cross Efficiency** — solving the first layer cross in <8 moves, planning during inspection
- **F2L (First Two Layers)** — 41 cases, intuitive vs. algorithmic approaches, pair recognition
- **OLL (Orientation of Last Layer)** — 57 algorithms for orienting the last layer
- **PLL (Permutation of Last Layer)** — 21 algorithms for permuting the last layer
- **Lookahead** — tracking next pieces while executing current moves
- **Finger Tricks** — optimal finger movements for speed and efficiency

### 3. Training & Competition
- **Deliberate Practice** — algorithm drilling, solve analysis, weakness identification
- **Competition Psychology** — inspection strategy, handling pressure, consistency
- **Hardware** — cube selection, tensions, lubrication, maintenance
- **Metrics** — TPS (turns per second), move count, inspection efficiency

### 4. Advanced Concepts
- **Algorithm Optimization** — choosing variants, fingertrick-friendly sequences
- **Color Neutrality** — solving from any starting color
- **Advanced F2L** — multislotting, winter variation, VHLS
- **Advanced Last Layer** — ZBLL, COLL, 1LLL approaches

## Intermediate-Level Focus

For an intermediate student (already knows beginner method, sub-60 seconds):
- Master efficient cross solving (inspection + execution)
- Build intuitive F2L understanding before heavy algorithm memorization
- Learn 2-look OLL and 2-look PLL first, then expand
- Develop lookahead as the primary speed multiplier
- Establish good finger trick foundations early
- Understand when to learn more algorithms vs. improve execution
