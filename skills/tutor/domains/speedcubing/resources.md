# Speedcubing — Resources

## Primary Sources (for lesson content)

### Structured Courses
- **[CubeSkills by Feliks Zemdegs](https://www.cubeskills.com/)** — Most comprehensive course, beginner through advanced. Feliks (former WR holder, 8.75s average) breaks down CFOP systematically. Covers cross, F2L, OLL, PLL, lookahead, finger tricks. Excellent for intermediate students. Free tutorials + premium content.
- **[J Perm CFOP Guide](https://jperm.net/algs/cfop)** — Clear visual algorithm sheets for every CFOP stage. Includes recommended learning order, algorithm variants, fingertrick notation. Best all-in-one reference.
- **[SpeedSolving Wiki](https://www.speedsolving.com/wiki/index.php/Main_Page)** — Community-maintained encyclopedia. Deep articles on methods, techniques, history. Good for conceptual understanding and method comparison.

### Algorithm Databases
- **[AlgDB.net](https://algdb.net/)** — Searchable database of algorithms with multiple variants. Shows 3D cube visualization, fingertrick-friendly versions, popularity ratings. Essential for finding alternative algorithms.
- **[CubeDB](https://cubedb.net/)** — Another algorithm database with subset trainers (OLL subsets, PLL recognition practice).

## Supplementary (for engagement)

### Video Channels

### Interactive Tools
- **[CSTimer (cstimer.net)](https://cstimer.net/)** — Most popular web-based timer. Features: scramble generation, session management, statistics (ao5, ao12, ao100), graphs, solve export. Cross-platform, works offline.
- **[CubeTimer](https://chrome.google.com/webstore/detail/cubetimer)** — Chrome extension timer with similar features to CSTimer.
- **[Twisty Timer (mobile)](https://play.google.com/store/apps/details?id=com.aricneto.twistytimer)** — Android timer app with solve tracking, scramble types, PLL/OLL trainers.
- **[ChaoTimer (mobile)](https://apps.apple.com/us/app/chaotimer/id1286617573)** — iOS timer app, clean interface, statistics tracking.
- **[VisualCube](http://cube.rider.biz/visualcube.php)** — API for generating cube state images. Used in algorithm sheets and tutorials. Useful for creating custom study materials.
- **[AnimCubeJS](https://cubing.github.io/AnimCube/)** — Embeddable 3D cube animations for visualizing algorithms. Good for building custom practice tools.

### Algorithm Trainers
- **[AlgTrainer (speedcubedb.com)](https://speedcubedb.com/a/3x3/)** — Drills for OLL/PLL recognition and execution. Shows cube state, you select algorithm. Tracks speed and accuracy.
- **[BestAlgorithm.com](https://bestsiteever.ru/oll/)** — OLL/PLL trainers with statistics. Focuses on recognition speed.
- **[Kuebiko Cube Algorithms](https://kuebiko-cubing.github.io/)** — Clean algorithm reference with subsets, variants, popularity data.

### Code & Repositories
- **[Cubing.js](https://js.cubing.net/cubing/)** — JavaScript library for cube visualizations, simulations, algorithm parsing. For students interested in building tools.
- **[kociemba (Python)](https://github.com/muodov/kociemba)** — Optimal Rubik's Cube solver using Kociemba's two-phase algorithm. Demonstrates computer solving approach vs. human methods.
- **[tnoodle (Java)](https://github.com/thewca/tnoodle)** — Official WCA scramble generator. Shows how competition scrambles are created.

### Hardware Resources
- **[SpeedCubeShop](https://speedcubeshop.com/)** — Major US retailer. Good for understanding cube options, reading reviews. Setup guides for lubrication and tensions.
- **[TheCubicle](https://www.thecubicle.com/)** — Another major retailer with setup services and tutorials.
- **[r/Cubers Wiki — Cube Recommendations](https://www.reddit.com/r/Cubers/wiki/which_cubes_to_buy)** — Community-maintained buying guide by price point and skill level.

## Unexpected Connections

### Mathematics
- **[Group Theory & Rubik's Cube](https://en.wikipedia.org/wiki/Rubik%27s_Cube_group)** — The cube represents a group of order 43,252,003,274,489,856,000. Connects to abstract algebra, permutation groups, symmetry.
- **[God's Number (20)](https://www.cube20.org/)** — Proven in 2010: any cube state solvable in ≤20 moves. Required massive computation. Demonstrates gap between human methods (~60 moves) and optimal solutions.
- **[Commutator Theory](https://www.speedsolving.com/wiki/index.php/Commutator)** — Mathematical structure underlying intuitive F2L and advanced techniques. ABA'B' sequences.

### Cognitive Science
- **[Skill Acquisition Studies](https://www.sciencedirect.com/topics/psychology/motor-learning)** — Speedcubing as model for motor learning research. Deliberate practice, chunking, automaticity.
- **Pattern Recognition & Expert Performance** — How top solvers achieve instant OLL/PLL recognition. Relates to chess expertise, medical diagnosis, other pattern-heavy domains.

### Robotics
- **[CubeStormer 3 (Lego robot)](https://www.youtube.com/watch?v=X0pFZG7j5cE)** — Robot that solved cube in 3.253s (2014). Shows computer vision + algorithm execution. Beaten by human WR (3.47s).
- **[MIT Robotic Cube Solver](https://www.youtube.com/watch?v=ixTddQQ2Hs4)** — Min2Phase algorithm implementation. Research in manipulation and planning.

### Blindfolded Extensions
- **[Old Pochmann Method](https://www.speedsolving.com/wiki/index.php/Classic_Pochmann)** — Beginner blindfolded method using memorization and setup moves.
- **[M2/R2 Methods](https://www.speedsolving.com/wiki/index.php/M2)** — Advanced blindfolded techniques. Completely different skill: memorization >> execution speed.

### Art & Design
- **[Cube Mosaics](https://www.youtube.com/results?search_query=rubik%27s+cube+mosaic)** — Using hundreds of cubes to create images. Requires color pattern solving.
- **[Cube-based Sculptures](https://www.reddit.com/r/Cubers/search?q=sculpture)** — 3D structures from multiple cubes.

### Cross-Training
- **[Finger Independence Exercises](https://www.youtube.com/results?search_query=finger+independence+piano)** — Piano technique videos applicable to cube finger tricks.
- **[Reaction Time Training](https://humanbenchmark.com/tests/reactiontime)** — Games that improve inspection-to-execution start speed.
- **[Typing Speed Training](https://www.keybr.com/)** — Similar motor skill development: muscle memory, speed vs. accuracy tradeoff, deliberate practice.
