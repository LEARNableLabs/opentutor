# Narrative Theory — How Stories Work — Domain Teaching Config

## Exercise Types
This domain uses a mix of delivery formats:
- **concept-focused mini-lessons** — 10 lessons (37%)
- **Socratic questions** — 7 lessons (26%)
- **real-world application challenges** — 5 lessons (19%)
- **review and consolidation sessions** — 3 lessons (11%)
- **teach-back exercises (student explains)** — 2 lessons (7%)

Primary format: concept-focused mini-lessons.

## Resource Types
This domain has strong coverage in: textbooks, video lectures, interactive tools, academic papers, code repositories, online courses. Prioritize these when recommending resources.

## Difficulty Curve
Balanced progression — steady difficulty increase with regular consolidation.

Distribution: 33% accessible (1-2), 44% standard (3), 22% challenging (4-5).

Difficulty peaks:
- Day 12: "Who is narrating, and where are they?" (difficulty 4)
- Day 13: "Why do frame narratives use stories-within-stories?" (difficulty 4)
- Day 15: "How does free indirect discourse blur narrator and character?" (difficulty 4)
- Day 23: "How do readers fill in narrative gaps?" (difficulty 4)
- Day 25: "How does storytelling work across different media?" (difficulty 4)

## Domain Hooks
This field covers narrative theory — how stories work, with applications across theory and practice.

## Common Failure Modes
Students often struggle with the foundational concepts before building to more advanced material. Reinforce basics before progressing.
